# Ralsei 桌面宠物 — 代码审查与修复报告

审查日期：2026 年
审查范围：`ralsei_pet/`（约 2.4 万行 Python：`src/main.py` 约 8300 行 + `modules/` 21 个模块 + 测试/诊断脚本）+ 根目录启动脚本 `run.py`。
方法：7 个并行深度审查代理逐行阅读 + 本机静态验证（py_compile / pyflakes / 全模块导入冒烟 / offscreen 与真实桌面 GUI 事件循环回归 / 数值模拟），全部结论经亲自读码核实。

严重度约定：P0=崩溃/数据丢失/无法启动；P1=明显功能错误；P2=边界条件触发；P3=维护/质量。

---

## 一、结论概览

- **未发现 P0**：应用可正常启动、加载 1106 个 PNG / 380 组动画，构造与长时间事件循环无异常。
- **已修复 25 项问题**（其中 P1 级 13 项、用户可感知 P2 级 10 余项、项目卫生 2 项），修复后经真实桌面 GUI 回归全部通过。
- **遗留建议**（P2/P3，多为架构级/清理级，详见第四节）已在报告中列明，未做高风险改动以免引入回归。

## 四、遗留问题与建议（未修改，供后续排期）

### P2（建议尽快处理）
1. **多显示器坐标系不统一**：主移动用虚拟屏矩形（支持负坐标副屏），但 main.py 另有约 23 处 `QApplication.desktop().availableGeometry()` 按主屏 clamp —— 副屏上的宠物跳跃/躲猫猫/弹跳/随机游走可能到不了目标或位置错乱。建议统一封装 `_screen_rect()` 一处替换。
2. **双击 = 2×单击 + 双击**三重反应叠加（Qt 双击序列触发两次 press + 一次 dblclick）。
3. **`check_text_content` 一次性 `f.read()` 整读文件**：桌面有超大文本时会卡 UI；建议只读头部 64KB + 大小预检。
4. **AI 命令轮询在主线程调用含 2 秒网络探测的 `get_system_info()`**：接入真实 provider 后每 2 秒轮询可能冻结 UI；应移后台线程（`cpu_percent` 无 interval 版）。
5. **躲猫猫胜利探测按窗口标题包含文件名判定**：`"障碍物1"` 是 `"障碍物1_2"` 前缀会误判；建议精确匹配。
6. **energy_hunger 与 pet_ai 休息“双轨”**：AI 让宠物休息不触发数值恢复、critical 自动休息期间 AI 仍可能走动；建议把 `is_resting` 接到 pet_ai 状态机。
7. **`emotion_system.react_to_event` 有 10+ 个 main.py 传入的事件名无对应分支**（saw_food/saw_recycle_bin/found_window 等）→ 静默无反应；建议补分支或对未知事件打一次告警。
8. **`pet_interaction.py` 全模块未接线**（孤儿）：main.py 内另有一套身体分区/手势识别（重复编码）；建议二选一收敛。
9. **`dialogue_ui` 历史区无限增长 + 光标闪烁每 0.53s 全量 `setHtml` 并强制滚底**：长会话内存与性能风险。
10. **`social_growth` 成就随机 10% 解锁且奖励递归加经验**（当前未被调用，接线后会连锁暴涨）。
11. **sound_manager `_play_ogg` 每次新建 QMediaPlayer**（parent 常驻）虽有清理，仍建议改复用单播放器。

### P3 / 清理类
1. **危险调试脚本**：`diag_real.py`（wmic+taskkill 杀含 “ralsei” 的 python 进程、rmtree 桌面上名字含“障碍物”的文件夹）、`diag_spell.py`（`taskkill /F /IM python.exe`）——建议删除或加环境变量开关，勿随项目分发。
2. **测试脚本冒充**：6 个 `test_window_detection*.py` + 5 个 PyQt 冒烟 + `test_jump_simple.py` ×2 等互相拷贝、无断言、`app.exec_()` 需手关，且被 pytest 收集会执行真实 GUI 副作用；`tests/` 下两个文件无 `def test_*`。建议去 `test_` 前缀迁移到 `tools/` 或删除。
3. **硬编码旧机路径**：`src/test_basic.py`、`src/test_with_log.py` 等仍指向不存在的 `c:/Users/23002/Documents/trae_projects/...`，会误导排障。
4. **备份/产物**：`*.py.bak/.backup_before_*`（约 1.7MB）、`config.json.backup.*` ×106、`animation_history.json` 743KB、30+ 日志文件 —— 清理或确认纳入 `.gitignore`（已加）。
5. **README.md 过时**：素材路径（Documents/trae_projects）、运行方式（未提 `run.py`）、目录结构（缺 15+ 模块）、“改源码调运动节奏”等；建议重写关键章节。
6. **`search_summarizer.py`**：bs4 依赖未装、query 未 urlencode、Google DOM 解析脆弱 —— 属“上网摘要”断链功能，接入前需补齐。
7. **`weather_system`**：夜间概率调整后总和 <1（夏季夜晚约 18% 概率兜底回 sunny）；断网探测 1.5s 在主线程；建议归一化 + 后台探测。
8. **`dialogue_system` 关键词冲突**：“清理”分支被更早匹配截获而不可达；“爱/可爱/不爱”“不喜欢/喜欢”否定句误判 —— 建议关键词优先级/否定词处理。
9. **动画元数据分散 5+ 处**（`_need_advance` 白名单、`group_priority_map`、`animation_priorities`、API 动作表、hover 表）——新增动画需同步多处，建议集中。
10. **`sprite_loader`**：缺帧仅灰块占位无聚合告警；`get_face` “face_”前缀约定脆弱；`frame_container_size` 死计算；`scan_and_group_assets` 帧号去重缺失。
11. **RPS 统计**：`total_games` 等键从不自增（统计恒 0）。
12. **`PerformanceMonitor.print_stats()` 空实现** + `monitor_performance` 未被使用；`main.py` 重复 `import time` 等小瑕疵。
