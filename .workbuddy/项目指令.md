# 项目指令 · 桌面宠物（Deltarune Ralsei 桌宠）

## 这是什么
用 PyQt 做的 Deltarune 角色 Ralsei 桌面宠物。核心口径：**把原作的世界搬到桌面（桌面即场景）**，一切根据原作，素材只从游戏源文件里找。

## 工作流（顺序不许跳）
1. 先问细节，一次问一个，「只要细节可能不准就问」；
2. 说出实现方案：改哪个文件、怎么改、预期看到什么、风险、哪部分不做；
3. 等用户回「可以」才动手，沉默不算点头；
4. 纯执行类（跑回归、提交、删文件）不问，直接做。
用户没答的细节：先把默认值明说出来，再按默认推进，不能自己咽下去。

## 留痕纪律
- 每轮改动完成即 commit + push，不攒批。
- 改文件只用 Write / Edit，禁止用 shell 重写文件（会改 EOL）。
- 工作日志 append-only，不覆盖。
- 处置文件先禁用 / 归档，不直接删。

## 不可回退的契约（违反即返工）
- 取景只认虚拟屏幕矩形 `_virtual_screen_rect()`，不用 `availableGeometry()`（它只覆盖主屏）。
- 能不能站，只认 `floor_visible_contains`；禁 `WindowStaysOnTopHint`。
- 记忆读写只走 `data_store`，正文在 `D:\RalseiMemory`，卷标定位禁硬编码。
- 只有主角团（最多加 Lancer）能上电脑桌面，其余角色留在场景里。
- 素材零像素改（`assets/faces/` 190 图 29 个 id 按原样）。

## 代码在哪 · 怎么验
- 源码 `ralsei_pet/`，入口 `ralsei_pet/src/main.py`（单实例锁 `Global\RalseiPetMutex`）。
- 回归 `code-quality-audit/regress/run_all.py`，判据必须**全 IDENTICAL**；只有改了断言或文案才用 `--only <suite> --update`。
- 改码前先跑一遍回归，改完再跑。禁止为了凑绿去改判据。
