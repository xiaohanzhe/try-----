## 五、教训（写进 MEMORY.md 了）
1. **别把"某条链路没有节流"当结论写进决策文档** —— 落笔前先 grep 常量与调用点。这轮两处
   overstatement 都是没看 `speak_event` 尾部那道 `EVENT_SPEAK_MIN_INTERVAL` 闸。
2. **断言别写成"这个函数里没有 `add_dialogue`"**：同一函数里可能有**合法的**另一处直接显示
   （`rest()` 的"拒绝原因"分支）→ 判假红。要锁**具体那一处**（needle 不存在 + 计数 2→1 双条件）。
   C10 第一次就是这条踩的（`rest.add_dialogue=1`）。
3. **PowerShell 捕获 Python 的 UTF-8 stdout 毁证据（第 3 次踩）**：`Out-File -Encoding utf8` 收
   `run_all.py` → 乱码。正解：**直接 `Copy-Item` `regress/_out/<suite>.txt`**（Python 自写真 UTF-8），
   或先 `[Console]::OutputEncoding = [Text.Encoding]::UTF8` 再 Out-File。
4. **别只数 `main.py` 就以为迁移范围只有 main.py** —— batch 2 迁的是 `modules/energy_hunger.py`，
   套件 C1 的 main.py 计数不变，得另加断言。
5. PowerShell 里 `New-Item`/`Out-File` 到一个**不存在的父目录**会 exit 1 且无输出 ——
   脚本里报"命令完成但无 stdout"时先确认目录。

## 五、教训（写进 MEMORY 了）
① **换底座 ≠ 改配置**：采样参数烘在 Modelfile 里，`api_client` 只发两项 —— 不重新 build 就静默漂移。
