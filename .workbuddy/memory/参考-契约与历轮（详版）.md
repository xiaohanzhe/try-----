## 4. 勿回退契约

### 4.1 多屏
禁用 `QApplication.desktop().availableGeometry()`（只返主屏 → "瞬移"根因），用 `_virtual_screen_rect()` /
`_current_screen_rect()` / `_clamp_pos_to_desktop()` / `_desktop_floor_y()`。物理量必须钳 `dt≤0.1s`（否则卡顿后单帧 dt 变大 → 位移二次放大 → 同一种"瞬移"）。

### 4.2 甩飞 / 抛物线
判定只在 `mouseReleaseEvent`（`_drag_samples` 0.12s 窗口，`_FLING_SPEED=900` / `_BOUNCE_SPEED=250`）；
初速只由松手速度定（等比缩放 + **矢量和**限幅）；`_fall_vy0` 只在第一帧记录；清理点共用
`_FALL_VELOCITY_ATTRS` / `_FALL_STATE_ATTRS`；落地相位 `_fall_phase_start`+`_fall_flight_time`+`_fall_landed`；
空中接住减速积分 `s=v0·t·(1-t/(2·dur))`。

### 4.3 动画
`fps=6`；自主说话唯一入口 `start_autonomous_speech()`（`AUTONOMOUS_SPEECH_MIN_INTERVAL=600.0`），
**AI 关闭必须沉默、不得回落内置台词**；不劫持鼠标、拖拽 1:1、起身类 `play_animation_once(...,restore_to="idle")` 只播一次。
**特殊动画（#13）来源只三类**：① `ai_driver` 决策 ② 用户显式交互 ③ 物理状态机（fall/splat/land/jump/wake）。
**环境自动触发不得自行播动画**，只能 `ai_driver.note_event()` 上报观察（`react_to_desktop_element`→`_note_desktop_observation`、
`_react_to_video` 已收编）；`update_animation_by_emotion` 与 `on_mouse_hover` 已空实现。
播放期 `_special_anim_locked()` 禁移动且 **force 也不能打断**；待机循环需原地静止 ≥`IDLE_LOOP_MIN_SECONDS=180` 才推进帧；
切换位置一致靠 `_anim_anchor_offset`/`_compose_anchored_sprite` 按 alpha 包围盒中心对齐（idle 偏移 (-20,+2.5)）。

### 4.9 「建楼」楼层系统（第十三～十八轮，本项目最贵的一条线，勿凭直觉"重做"）
**口径**：楼层 = 窗口的"**可见区域**"，不是整矩形（Windows 原生口径）。
- 几何：`visible_subrects(target,blockers)` 依次切（`_cut` 最多切 4 块、产出天然两两不重叠）；
  `MIN_FLOOR_VISIBLE_AREA=40*40`，语义是**"够不够站"**（1px 缝 1000px² 不成层，4px 4000px² 成层）。
- 编号：`platform_height=(n-i)*5` **按名次**（前=高），`DESKTOP_IDENTITY='desktop'` 恒 0 层；
  **通用规则：可见面积跌破阈值 = 该层"暂时不存在"，且它不再遮挡更低窗口**。
- 查询：`floor_visible_contains` 是**唯一判据**（站立/下落/跳跃/边缘全走它）；`get_drop_destination`/`find_support_below`
  只取"**下面第一个**能接住的"（不许跨层）；`get_current_floor` **几何优先**，`WindowFromPoint` 只在几何判到桌面时做"**只向上**"兜底。
- 渲染：**禁用 `Qt.WindowStaysOnTopHint`**（永久置顶 = 遮挡从渲染层就失效）；改用 `_apply_pet_z_order()` →
  `SetWindowPos(pet, insertAfter=所站楼板)`。**顺序铁律：`show()` 有"提到前面"副作用 → 必须 `show()` 之后再调 z 序。**
- 上下动（第十四轮）：**楼层系统是跳跃的唯一入口** —— `check_nearby_windows` 拿不到楼层就直接 return。
  上跳落点必须过可见区域门（`nearest_visible_point` 吸附；触发几何照旧"贴边 `NEAR=60px`"，别改成"横向覆盖就跳"）；
  下跳显式 `adjacent_lower_floor`（**桌面返回 `None`**，**不穿透**是硬要求）；`current_window` 已降级为派生缓存
  （唯一写点 `_sync_window_cache_from_floor`）；落地当场结算（写 `current_floor`+`current_platform_z`、同步缓存、
  **立刻** `_apply_pet_z_order()`、播 `land` 一次）。
- 坠落（第十五/十七轮）：`start_falling(..., reason=)`；触发坠落只看**层高比较**（`new_h < old_h`，取自 `platform_height`）——
  ① 自己走出边缘→桌面 ② 关窗→桌面 ③ 关窗→下方还有窗口 ④ 新窗盖旧窗（`new>old`）**不摔**。
  起因分流在 `is_floor_valid(old_floor)`：**窗口还在 ⇒ 自己走出去**（常规动画）；**窗口没了 ⇒ 用户抽走楼板**（生气）。
  生气动画时长与素材由起因 `_fall_reason` **纯派生**（模块级 `_fall_splat_hold(pet)`/`_splat_animation_name(pet)`）：
  关窗 ≥5s / 挪楼板 ≥3s / 无起因 1.0s；素材 `splat_mad`。落地结算（`trigger_splat`/`handle_fall`）**只读不写**。
  坑：① 旧 `max_fall_duration = 5.0/3.0` 是**死参数**已删；② `handle_fall` 的 splat 时长别硬编码 `1.0`；
  ③ **甩飞路径必须显式 `self._fall_reason = None`**（否则上次关窗起因残留 → 甩飞也播生气版停 5s）；
  ④ 判定函数放**模块级**、**不要**做成 `RalseiPet` 方法（多个历史套件用 `SimpleNamespace` 桩驱动 `handle_fall`）。
- 层高闸门 + 跳/攀爬衔接（第十八轮）：`walk_induced = (new_h != old_h and is_moving and is_floor_valid(old_floor))`
  → 成立则先试 `_start_climb_transition`；**上楼够不着 ⇒ 保持原楼层**，**下楼够不着 ⇒ 服从重力**。
  入口只用既有属性 → 历史轻量桩仍走被动路径（这是 21 套件全 IDENTICAL 的原因）。
  **跳还是爬 = 单点选型** `_jump_kind_for_span(|Δplatform_height|)`（`≤CLIMB_SPAN_JUMP_MAX=5` 用 `jump` 家族、更大用 `climb_*`），
  结果存 `_jump_anim_override`，**`handle_jump` 每帧必须先读它**。落点"先让开再吸附"：`_climb_hdir` → `cur ± CLIMB_HORIZONTAL_RUN(90)`

## 10. 世界观**网图**（第二十一轮，2026-09-20）

### 10.1 为什么（用户口径，别改口径）
> 「我觉得你可以把他的世界观拆分成网图，这应该会更高效」

第二十轮把世界观改成按需召回后，检索靠**关键词打分** —— "聊到黑暗喷泉该不该顺带想起那个传说"
是**碰触发词表的运气**。拆成网图是把它变成**结构决定**：
**命中一块 = 直接想起来；沿边扩一块 = 顺着想起紧挨着的那一块。**

### 10.2 文件格式（解析器依赖，别改）
```
@@ <键>|<标签>|<触发词,触发词>
@@> <本键> -> <邻键>, <邻键>      ← 边行，紧跟块头，不算块体（不发给模型）
<块体>
```
- `@@>` 行**单独一行**，位于块头之后、块体之前。
- 有向图：一条 `@@>` 只声明"从这个键出发"，反向由对面那条负责。
- 悬空边（指向不存在的键）在解析期被挑出，不参与召回。

### 10.3 代码契约（`modules/worldview_recall.py`）
- `_EDGE = re.compile(r'^@@>\s*([^\s>]+)\s*->\s*(.+)$')`
- `_parse()` 返回 `(blocks, adj, dangling)`；`adj` 只含**指向真实块**的边；
  **自环被 `if t == b.key: continue` 主动滤掉**；同一边去重保序。
- `load_graph(path)` → `(blocks, adj, dangling)`（给体检/锁用）；
  `load_blocks(path)` 保留为旧调用（只要 blocks）。
- `recall()`：**第一层**取关键词命中（种子，按分降序、同分按文件顺序）；
  **第二层**只在名额没用满时沿种子出边补邻块，**只扩一层、不链式**。

### 10.4 两条铁律（想过一轮的取舍，别改回去）
1. **邻块不要求自己被 cue 命中。**
   最初的写法给邻块加了 `_MIN_SCORE` 同门槛 → **扩图永不开火**：
   能命中邻块的 cue 本来就会直接命中邻块（那它早就是种子了）；
   真正需要扩的场景（cue 只说"喷泉"、没想到"传说"）恰好是邻块得分 0 的时候。
   **正确判据：「邻块与种子相关（有边）」，不是「邻块与 cue 相关」。**
   前提（种子命中）本身就是闸门 —— 闲聊产生不了种子，自然扩不了图（K17 盯着）。
2. **不做二阶扩图。** 只从种子出发扩一层，否则一条边链能把整个世界观拖进来。
