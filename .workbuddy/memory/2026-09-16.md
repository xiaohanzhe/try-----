## 第十三轮返工：证据文件被我自己写成了乱码（用户反馈驱动）

用户："你生成的代码报告是啥啊" → "不是，你那里面的字都不是字。"

### 现象与根因
`_evidence/round13_native_probe.txt` 打开后中文全是 `閲忕翰鑷` 这类方块字。
根因：我用 **PowerShell 的 `*>` 捕获 Python 脚本 stdout** 存证据 —— PowerShell 把原生程序输出
**按控制台代码页（GBK）解码、再按 UTF-8 重写** → UTF-8 字节二次编码。**文件内容真坏了，不是显示问题。**

对照表（已写进 MEMORY.md 环境铁律 10）：
| 做法 | 结果 |
|---|---|
| 脚本内 `open(...,encoding='utf-8')` 自写 | ✅ 干净 |
| `& py x.py *> o.txt` / `\| Out-File -Encoding utf8` | ❌ 中文必坏 |
| `Copy-Item` 搬运干净文件 | ✅ 逐字节 |
| `Write` 工具覆盖**原本带 BOM** 的文件 | ⚠ 内容更新但 **BOM 保留** → 去 BOM 必须 Python 重写 |

### 修法
重跑 `probe_native_occlusion.py` / `_probe_dpi.py`（它们自己写 `_out_*.txt`）→ `Copy-Item` 搬进 `_evidence/`；
删掉那份还夹着 `NativeCommandError` 报错行的 `.txt`；`round13_default_launch_ok.md` 用 Python 去 BOM；
把该文件里我写进去的**乱码样本**换成文字描述（否则绊线判据会把干净文件认成乱码）。

### 防复发：`code-quality-audit/tools/check_evidence_encoding.py`
`--out` 自写报告（用 PS `>` 捕获它同样会坏 —— 工具自己得示范正确姿势）、`--strict` 让告警也算失败。
两级判据：**确定性损坏**（非法 UTF-8 / U+FFFD，退出码非 0）／**告警**（BOM / 疑似乱码绊线）。

**最关键的一条教训**：第一版乱码判据用教科书式**往返法**（`encode('gbk').decode('utf-8')` 成功即乱码），
**对本次故障完全失效** —— PowerShell 那次解码**有损**，GBK 编不回原字节，往返直接抛 `UnicodeDecodeError`
→ 判据**永不触发** → 扫描报 `mojibake=0` 的**假清白**。改成"命中 ≥2 特征字"的绊线（会误报，明确标注需人工确认；
跳过工具自身因为源码必然含特征字）。
> **"能力自评失准"比"能力不足"更危险 —— 一个报 0 的检查器会让人以为已经验过了。**

### 关键实现
- `floor_manager.py` 新增 `adjacent_lower_floor`（按 `platform_height` 名次取相邻下层；**桌面返回 `None`**）
  与 `nearest_visible_point`（把落点吸附进可见区域；桌面原样返回）。
- `main.py` 新增 6 方法：`_floors_for_jump` / `_visible_landing` / `_floor_entry_plan` / `_nearest_floor_jump` /
  `_start_floor_jump` / `_sync_window_cache_from_floor`。`check_nearby_windows` 楼层可用即**早返回**，
  **不 continue 到旧启发式**（留着旧段 = 留着"跳到看不见的地板"这个 bug）。
- `start_jump` 签名扩为 `(target_window, window_edge, target_floor=None, target_pos=None)` —— 给 `target_pos`
  就直用，不再从裸矩形反推落点。
- 保留"贴边才跳"的触感（`NEAR=60px`），只换判据来源（DWM 可见边框 + 可见性门）→ **手感不变、判据变对**。
- 下跳**显式**取相邻层，不从 `get_jump_destinations` "顺便拿"：那里按 x 范围过滤，而"半个身子探出楼板"
  恰好 x 已出范围 → 会被漏掉；而要求明写"必须先跳到 2 楼"。

### 落地（批次二）细节
- `handle_jump` 完成帧：写 `current_floor`+`current_platform_z` → `_sync_window_cache_from_floor` → `show()/move()`
  → `spatial_pos["z"]` → `_apply_pet_z_order()`（**落地那一瞬**，不等 1s 节拍）→ `play_animation_once("land")`。

  "跳跃被判穿透"**不带起因**（不算用户行为，套件 G 专门反证）。
