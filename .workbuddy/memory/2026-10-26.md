# 第113轮k · 特定事件 → 去哪儿（**本轮定案**）

## 口径（逐字）
「特定事件就是指，**吃饭，活动，休息，做任务**等，他能**识别出来要去哪**，并**给出建议**，
  就像人类之间问『咱吃饭去吧』，别人会回答『**那要不去 XXX 家餐厅**』。」

## ★★★ 拆成三件事，混成一件就做错
① **听懂**（`detect_activity`，只认**意图词**）② **知道哪儿真能干**（`place_matches`，
只认**地点词**）③ **自己组织台词**（`activity_hint` 只给事实，**不写死模板** —— 113i 的 A12d）。
★★ ①② 必须是**两张表**：混成一张就变成「因为人在餐厅所以他在吃饭」，而人说话是
「我想吃饭所以去餐厅」。**因果倒置**。

## 5 个真错误（全部靠 **2166 场景全量人读** 抓的，6 个样本一条都看不出）
1. **`diner` 被吃掉**：`ch1.hometown.diner` 的 `name` 是 `家乡·diner` 但 `name_derived=True`
   ⇒ `_scene_place_label` 判"无名"⇒ 输出「真有的地方：**家乡**」。用户要的「XXX 家餐厅」没了。
   ⇒ `place_label(area,detail,core,hits)`：真名 → 否则**原作 id 末段** → 再补中文类型括注
   ⇒ `家乡 · diner（餐厅）`。`_scene_place_label` 加 `with_chapter=True`（**默认路径逐字不变**）。
2. **同一家医院的走廊/大厅/病房**被当三个去处 ⇒ 去重键 `(区名, 中文类型名)`，留 sid 升序第一条
   ⇒ 医院/图书馆/学校。★ **不许过度去重**（`我的城堡镇` 的餐馆 ≠ 咖啡店）。
3. `hospital hallway` ⇒「去医院**走廊**办事」⇒ `trim_core_at_type()`：**截到类型词为止**
   （之后的 `lobby/hallway/upstairs/interior` 是房间；之前的 `icee`/`castle`/`fire` 是店名前半截，必须留）。
4. `Research Station（车站）` ⇒ **翻译表越权**。`station`/`dock` **退出** `PLACE_GLOSS`
   —— **猜错的翻译就是编造地名**，比留英文更糟。
5. `系统与演出 · shop（商店）` ⇒ `ch5.system` 是 3 个**调试房**（`plat_lab`/`rhythmgame_editor`/
   `shop_ch5`）⇒ `PLACE_SKIP_AREA_IDS`（**按区 id 判**，`系统与演出` 读起来像真地名，按名字判会漏）。
   位置标签**照旧显示**（人在里面也得知道自己在哪）。
6. 顺带：`c asgore kitchen` 的 **id 单字母残留** ⇒ `strip_room_index` 去**行首单字母**。

## 人味真错：`我不饿` 会推荐餐厅
`detect_activity` 认否定（`_NEG_HEADS`，窗口 3 字）。两条踩出来的：
★ **只否被否那一处**（`我不累，出去逛逛` 的 `出去` 仍要命中 play）；
★★ **否定不跨句**（`_NEG_BREAK`）—— 没它 `出去` 被逗号那边的 `不` 否掉，退回命中的是 `逛`
   ⇒ `check113k B9` 因此断言 **`('play','出去')` 整个元组**，只判 kind 会漏。
代价：`好不容易吃上了` 会被误否（方向是**沉默**不是乱推荐，可接受）。
