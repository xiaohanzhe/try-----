### ★★★ 三层分工模型（本轮的骨架，别混淆）

```
npc_intent   自发：他今天想干什么（wander / visit_friend / go_home / visit_favorite / explore_unknown / stay）
npc_errand   被派：有目的地、有期限、有结果                      ★ 本轮新增（层5）
npc_roam     位置：把"他现在该在哪"落成驻留覆盖（唯一位置真源）
```

- `npc_roam` 只能表达「**他自己**想去哪」，**不能**表达「**我派**他去哪办事」⇒ 中间必须补一层。
- ★ 差事**只告诉宿主**"该把谁挪到哪"（`step()` / `working_positions()` 返回值），
  **位置的写入仍由宿主** `roam.put()` 完成 ⇒ 位置真源**永不复制**。

### ★ 生命周期（三段，单向，不回头）

```
traveling ──(到点)──▶ working ──(到点)──▶ done
 在路上 ⇒ scene_now()=None      已到 ⇒ =dest_scene      办完 ⇒ 撤覆盖 + 结果定格 + 落记忆
```

- `traveling` 返回 **`None`**（而不是"出发地"）= **明确交接**："他在路上，位置没人改，保持原样"。
- `DEFAULT_TRAVEL_SECONDS = 90.0` —— ★ **不是瞬移**：与"当原作门逐门寻路"同源，
  出门办事**要有过程**（否则"我中途进去"永远看不到他在路上）。
- `DEFAULT_WORK_SECONDS = 300.0` · `MAX_ERRANDS = 64` · `MAX_DONE = 128`（超了 FIFO 丢最老）。
- ★★ `Errand.from_dict` **缺 `start`/`arrive_at`/`finish_at` 任何时间字段即返回 `None`** ——
  防"working 但没有 finish_at ⇒ 该 NPC 被永远压在某个场景上 ⇒ 回不了家"。
