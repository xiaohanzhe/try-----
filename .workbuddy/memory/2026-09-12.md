## 第二轮审查：深度代码审查（独立验证版）

**所有结论逐条回源核实**，并推翻了 3 条初筛误报。产出 `深度代码审查报告_独立验证版.md`。

### 关键发现
- **P0-1** 全项目无 `sys.excepthook`；`dialogue_ui.py:1173`（"打开"分支）未包 try，
  而同文件其他分支都包了。PyQt5.5+ 槽内未捕获异常 → `qFatal()→abort()` 直接杀进程。
- **P0-2** 多屏坐标两套体系混用。正确版 `main.py:7588 _virtual_screen_rect()`（用 76/77/78/79），
  错误版 `QApplication.desktop().availableGeometry()` 遍布 20+ 处（249/1057/1304/1652/2070/2097/
  2256/2336/2550/2611/2798/2846/2906/4062/7031/7537/7722/7733/8038/8130/8185/8365）
  → 副屏每帧被 `max(0,...)` 拉回主屏。同根因：`desktop_interaction.py:1006` 拿 78/79 当边界
  未减原点 76/77 → 左侧/上方副屏窗口被 `rect[2]<0` 全部误过滤。正确写法参考 `command_manager.py:58-63`。
- **P0-3** `main.py:4899` `self._last_drag_pos_prev = self._last_drag_pos` 无条件覆盖
  （4857 行刚把 `_last_drag_pos = target_pos`）→ 4920 行 `dx=dy=0` → `release_speed` 恒 0
  → 4925「甩飞」/4948「弹跳」/4967「旋转」**全是死代码**。且这段在 `mouseMoveEvent` 的
  else（无按键）分支，`mouseReleaseEvent:5115` 根本不处理释放物理。
- **P1** `social_growth_system.py:483-518` 进化跳级（4→6 级时 5 级形态永久跳过；10 级 1→3 跳过 2）；
  `:520-557` 成就 conditions 只覆盖 12 个，`level_10/level_20/evolution_master/explorer/creator/
  storyteller/social_butterfly` 无 condition 且全项目 `_unlock_achievement` 仅一处调用 → 永久无法解锁；
  `memory_system.py:141-178` `add_memory`(55-59) 无 `id` 字段 → 关联记忆恒返回 `[]`（功能完全失效）；
  `dialogue_system.py:1166` 先于 `1176` 命中，"不喜欢"含"喜欢" → 情感判断反向；
  `:747` `and/or` 优先级错误；`main.py:7892` 施法兜底 `frames_seen >= 22` 在 spell 仅 11 帧下恒假
  （**实测** `spr_ralsei_spell_0..10` 与 `spell_left_0..10` 各 11 张）→ 无墙钟超时，安全网是死代码；
  `config_manager.py:22+166-182` 打包后写 `_MEIPASS` 只读目录，`os.replace` 必失败（被吞）→ 配置永远存不下；
  `main.py:4114` `video_watching_timer` 未 stop 旧定时器 → 重复触发；
  `desktop_interaction.py:301` `platform.system()=="Windows"` 写反（`getloadavg` 是 Unix 专属）；
  `main.py:8376-8406` 单实例检测里 `input()` 在 pythonw 下抛 EOFError 被外层 except 吞掉 → 保护失效；
  `main.py:41` `PerformanceMonitor` 无上限 append + 30ms 装饰器 → 约 66 次/秒内存泄漏。
