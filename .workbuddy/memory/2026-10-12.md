### ★ 工具链新坑（重要）
- **`github.com:443` 被沙箱代理拦截（502 / timeout）**，但 `api.github.com`、`codeload.github.com`、
  `ssh.github.com:443` 可达 ⇒ 常规 `git push` 全失败。
- 绕行：用 **GitHub Git Data API**（blobs→tree→commit→ref）推送。两个关键点：
  1. `git diff --name-only` 会 C 式转义非 ASCII 路径 ⇒ 必须 **`-z` + `core.quotepath=false`**，否则
     中文路径文件被误判为"删除" ⇒ tree 422 `GitRPC::BadObjectState`。
  2. blob 内容必须取 **`git cat-file blob HEAD:<path>`**（已归一化 LF），**不能用工作区字节**
     （CRLF）⇒ 否则远端 tree sha ≠ 本地 HEAD tree，树级核验 False。
- 核验方式：远端 commit tree sha **必须等于** 本地 `git rev-parse HEAD^{tree}`（本轮 `4b26d063…` 一致）。
- 最终：远端 main = `0aa1d099`，tree `4b26d063` == 本地 HEAD tree ✅。
