## 教训（本轮新增）
1. **别用 PowerShell 管道读模型的中文元数据**：`ollama show --modelfile` 经管道读出来全是 GBK 乱码
   （`浣犳槸涓€涓鑹叉壆婕?AI`），我一度误判"模型里的角色设定坏了"。
   改走 **Ollama REST API + 显式 UTF-8** 直读，确认 2003 字设定完好。**凡涉中文元数据，走 API 不经管道。**
2. **注入的 `current_time` 会滞后于系统真实时间**：本轮注入值写"2026-09-16 00:22"，
   `Get-Date` 实测 **2026-09-18 00:07**。**落盘前必须用 `Get-Date` 校准**，
   否则报告/日志文件名日期就是错的（本轮已 `git mv` 改名 + `--amend` 修正）。
3. **提示词里的"示例口头禅"对 ≤3B 模型是毒药**：会被当成必答模板复读。
   小模型的 few-shot 必须标"风格示范，不要照抄"并配输出护栏（去重/截断/重采样）。
4. **A/B 受控实验是判断"到底是模型不行还是接线不对"的唯一办法**：
   固定模型/问题/温度，只换提示词，一次就分清了。

### 教训（续，本轮新增）
6. **`/v1/chat/completions` 静默忽略 `num_ctx` 与 `repeat_penalty`**（顶层/options 都无效）；
   只有原生 `/api/chat` 的 `options` 或 Modelfile 的 `PARAMETER` 生效。
   → 采样参数**必须落 Modelfile**；参数 A/B 必须走原生端点，否则会得到"改了没区别"的假结论。
7. **persona 文件是 prompt，不是文档**：它是逐字进模型的，写 `**`/`#`/`>` 会被 3B 照学
   （实测输出过 `**听到也让我心里暖暖的**`），而对话框是逐字打字机渲染 → 星号原样显示给用户。
8. **护栏必须能在"忠实复刻链路的 e2e"里验收**：直接调护栏函数会得到"成功率 0%"的假象（没走重试）。
   e2e 要把**已采用的回复**累积成 `spoken` 当后续 `recent`，不能用"上一轮的原始输出"。
9. **测试桩漂移 ≠ 真回归**：`round6_verify` 的 B2/B3/B7/B8 全挂，根因是
   `start_autonomous_speech._on_reply` 新依赖 `_clean_ai_reply`，而第六轮的 `SimpleNamespace` 桩
   没绑该属性 → AttributeError 被宽 `except` 吞掉 → 把"已发起"误判 False。
   修法：① 回调内对护栏加防御 try/except；② 护栏方法内部**不依赖任何 `self.` 实例属性**
   （只用类属性/局部量），桩上可直接跑。**（先看 g2 输出的时间戳再下结论——我差点对着修复前的旧数据debug。）**
