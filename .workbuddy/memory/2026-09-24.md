- 会话开头系统提示 `MEMORY.md has exceeded the size limit and was truncated during injection`。

  把 `MEMORY.md` 从 **11,446 字符重写到 12,252 字符** —— **体积涨了 800，却丢了 4 个可检索令牌**：
  `真机打点落 CSV` / `真背景原样提取` / `chapter*10000` / `prefill 远慢于 decode`。

  `buildAgentMemoryPrompt` ⇒ `eh=200, ef=25e3` + `Buffer.byteLength(ea,"utf-8") > ef`
  ⇒ **上限 = 200 行 / 25,000 字节（utf-8 字节数，不是字符数）**，超限从尾部砍。
  实测事故后文件 = 111 行 / 20,932 字节 ⇒ **本来就在限内**。
  （另处 `eg=4e4`(40,000) 是 memory **工具**的单文件写作上限，别混用。）
