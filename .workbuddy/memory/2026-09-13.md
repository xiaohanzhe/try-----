### 本轮关键发现：一个躲过前四轮的 P0

**`main.py::_tick_spell_flow` 引用未定义名 `current_time`**（修复前 8120/8132 行）。
该方法内局部名是 `now`（8054 行 `now = time.time()`），模块顶层也从未绑定 `current_time`
（773/815 行的是 `self.current_time` **属性**，与裸名无关）。`cond_time_fallback` 在 casting
分支中无条件执行 → **每次施法每个 tick 必抛 NameError**。

后果链：异常被 `update_animation` 的 try/except 吞掉 → `_spell_stage` 永停 'casting' →
* `_spell_finish_cb` 永不触发 → `open_file`/`open_folder` 永不真正打开文件；
* 躲猫猫障碍物永不创建，`_hide_stage` 永停 'creating' → 游戏再也开不起来；
* `autonomous_agent` 永久 suspend、`pet_ai.trigger_action` 因 `_spell_stage` 非空而直接 return → **宠物僵直**；
* 每 100ms 打印一次堆栈。唯一脱困路径 = 用户拖拽/触摸/跳落。

为什么漏检：第三/四轮都把 `_tick_spell_flow`、躲猫猫全链标为"精读、防护完整"——这是跨函数
拼写/作用域错误，肉眼看不出来，**只有静态分析（undefined name）或运行时才能暴露**。
