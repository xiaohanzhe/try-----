**P0-2 `handle_jump` 竖直分量符号反了（抛物线结构上不成立）**：
`main.py:7708/7712` 用**标准 Y-up 弹道**公式（`+vy0*t - 0.5*g*t²`），而
`jump_start_pos = self.pos()` 是**屏幕坐标（Y 向下）** ⇒ 竖直加速度恒朝上（**反重力**），
**永远画不出"先上后下"的抛物线**。数值仿真（`sim_jump90.py`，g=500/T=1.0）：
- Δy=-100 / 0 / +200 时 `vy0` 分别 +200 / +300 / +500 ⇒ **前段朝屏幕下方沉**（同高跳先沉 90px）；
- Δy=-300 时 `vy0` 恰为 0 ⇒ 没有起跳、只靠"反重力"飘 250px < 目标 300px；
- `+50` 魔数让公式落点**恒定差 -50px**，`jump_progress>=1.0` 时硬吸附 ⇒ 落地瞬间跳变 50px。
★ **同文件自相矛盾**：`handle_fall`(8485 `+_gy*t`) 与甩飞(10437 `velocity_y` 负=上) 都用对了
Y 向下约定 ⇒ **只有 `handle_jump` 是反的**。
修法：`y = y0 + vy0*t + 0.5*g*t²`，`vy0 = (0.5*g*T² - delta_y)/T`（负=上），落点即精确命中，删掉 `+50` 与硬吸附。
