## 第七轮：发现并修复"文档化启动即崩"（R7-1）+ 真机验证尝试

### 发现
- 按 README 的 `cd src && python main.py` 启动，import 期崩：
  `ModuleNotFoundError: No module named 'logger_utils'`（main.py:98 → desktop_interaction.py:19），
  退出码 1、**窗口根本不出现**。
- 根因：`modules/desktop_interaction.py:19` 是全项目**唯一**裸的 `from logger_utils import`
  （其余 20 处都包 try/except），而 `logger_utils.py` 就在 `modules/` 里，
  `main.py` 却只把 `ralsei_pet/`（不含 `modules/`）放进 sys.path。
- **回归盲区**：G2 六个套件全都预置了 `src/`+`modules/`，恰好掩盖该差异 → 全绿却对真实启动零覆盖。

### 修复（提交 `cc1f5b8`）
- `modules/desktop_interaction.py`：导入加 try/except 降级（与其余模块一致）。
- `src/main.py`：`sys.path.append(<root>/modules)`（append+去重，标准库优先）——根因修复。
