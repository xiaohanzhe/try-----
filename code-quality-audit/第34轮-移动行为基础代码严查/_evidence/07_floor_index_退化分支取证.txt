====================================================================
场景：宠物站在「最高的那个窗口」上 → 用户把它关掉 → 重力坠落
====================================================================
[关闭前] 活楼层高度: [15, 10, 5]
         宠物所在层 h = 15
         is_floor_valid = True

[关闭后] 活楼层高度: [10, 5]
         stale platform_height = 15 （窗口已不在 underlying_windows）
         is_floor_valid(stale) = False
         sorted(floors+desktop) 高度 = [10, 5, 0]
         _index_of_floor(stale) = -1   <== 期望「指向不高于当前楼层的位置」
              但 -1 会被 range(idx+1, n) 当成「从第 0 个（最高的活楼层）开始」
         get_drop_destination -> h = 0 （正确应为 0=桌面；宠物会落到它**上方**那块板）

--- 影响面 2：adjacent_lower_floor 误报「无处可下」 ---
         adjacent_lower_floor(stale) = None   <== None 的语义是「已在最底层，下面没有楼板」
              但桌面(h=0)明明在下面 → 宠物无法用「向下跳」离开，只能等重力

--- 影响面 3：get_jump_destinations 把「存在的层」漏掉 ---
         候选高度 = [15, 10]
         含 0（桌面）? False  <== 桌面 h=0 被 current_index+1 的边界漏掉

====================================================================
结论：退化分支不是「不可达」，而是「stale 高于所有活楼层时必达」；
     返回 -1 不是安全的「未找到」哨兵，而是「比最高层还高」的语义。
