## 2. 改了什么

唯一产品改动：`ralsei_pet/src/main.py`，两处，**+19 / 0**。

### 2.1 `_bedtime_tick` ② 加闸（+16 行）

原路径：到点 → `go_to_bed()` → `scene.switch('desktop')`。
灵魂在暗世界/别处时，这一下**画面被拽回桌面，灵魂一步没动** —— 正是口径 ① 要禁的。

```python
            # ★★★ 第149轮（§109.5 口径 1）：「显示切换只跟灵魂」。
            ...
            _home = getattr(self, 'BEDTIME_HOME_SCENE', 'desktop')
            _cur = getattr(self, 'current_scene', None)
            if _cur and _cur != _home:
                if getattr(self, '_bedtime_defer_logged', None) != _cur:
                    self._bedtime_defer_logged = _cur
                    _log.info("[就寝] 显示在 %s（≠ %s）：不切显示，回桌面再睡", _cur, _home)
                return False
```

三条设计取舍：

1. **位置在"标记 `fired`"之前**。放之后 ⇒ 当晚已记 `_bedtime_fired_date`，闸只能管到明天，等于没管（`check149 C2` 锁这条）。
2. **只推迟、不标记 `fired`**。窗口内每 tick 还会试，用户一回桌面就立刻生效；窗口过了仍是既有行为（记"不再补睡"）。
3. `current_scene` 为 `None`（场景索引还没加载）时**不拦**，沿用原逻辑 —— 不把"不知道"当"知道"。

### 2.2 `__init__` 补声明（+3 行）

本项目纪律（同处注释「9 字段预声明」）：**字段集中声明，别靠 `getattr` 兜底，否则"没接线"会伪装成"运行时正常"**。
判据侧仍用 `getattr` 读，是为了让 `check91` 那种不带该字段的轻量桩不炸。

```python
        # ★ 第149轮：就寝闸的**日志去重**位（上次因「显示不在家」被推迟的场景 id）。
        #   只为避免每 tick 刷一行日志；**不是**判定依据（判定看 `current_scene`）。
        self._bedtime_defer_logged = None
```

## 3.3 同一个病，我自己又犯了一次 —— 所以加了一道闸

回填本报告的 §3.1/§5 之后，全量回归**又单条 DIFF**，红的正是 `check149`。原因是我自己的
`D2` 在 extra 里打了 `len(_REP)`（报告长度）—— 报告是**会一直改**的文档，回显它的长度就是回显时相量。
顺着查又发现两处：`A0` 打了 `main.py` 的**函数总数**（加一个函数就变）、`C1`/`C2` 打了**行号**
（谁在上面插一行就整体后移）。三处全是"判定没变、数字变了"。

⇒ 不只是把这三处改成布尔，还加了 `E5`：**扫本文件自己的 AST**，任何 `check(...)` 的第 3 实参
若用了 `%d` 格式化、或引用了 `lineno`，直接报红。写完 `E5` 当场又抓出两处
（`C9` 的"偏移 %d 分钟"、`D1` 的 `fn=%d`）—— 说明闸是真的在干活，不是摆设。

这条与本轮 `check79` 的修复、第146轮 `check138` 的修复是**同一个病的三次发作**：
判据可以断数字，但**不许把数字打出来**。
