# 第146轮 · `check138` 的输出不再回显"规模量"

> 承接第145轮报告 §8 遗留③。一句话：**第144轮只冻了"落盘"那一半，`stdout` 那一半没动** ——
> 于是"每加一个套件就要 `--only check138 --update`"这件事，从**文件**挪到了**输出**，一直没治。

---

## 1 病

`check138` D 段（分母闸）原来两行：

```python
check(u'D1 扫到的判据文件 ≥ 100 个', len(_targets) >= 100, u'%d 个' % len(_targets))
check(u'D2 扫到的 `check`/`ok` 调用 ≥ 2000 处', _n_calls >= 2000, u'%d 处' % _n_calls)
```

- `_targets` = 进 `SUITES` 的脚本数；
- `_n_calls` = 那些脚本里的 `check`/`ok` 调用数。

**每加一个套件，这两个数必然变** ⇒ 判定一个字没改，`check138` 报 DIFF ⇒ 每轮手工 `--update`。
这是"判据回显时相量"的第 9 次复发（前 8 次见 `check138` 抬头表）。

## 2 改法

只改 extra，判定一个字不动：

```python
check(u'D1 扫到的判据文件 ≥ 100 个', len(_targets) >= 100,
      u'过阈=%s（闸门 ≥100）' % (len(_targets) >= 100))
```

具体数值留在 `regress/_out/phase138.live.json`（已被 `.gitignore` 忽略）。

| 项 | 值 |
|---|---|
| 改动面 | `check138.py` **+12 / −2** |
| 新增 12 行 | 8 行注释 + 2 条判据各拆两行 |
| 删除 2 行 | **全部**是旧 extra（`recheck146_core H4` 逐行归类） |
| desc / 判定表达式 | 与 HEAD **逐字相同**（`H16`） |
| 冻结件 `phase138.json` | **字节未变**（`H20`） |

## 3 行为级证明（本轮真正的判据，不是"读源码觉得它不会变"）

`check146 B` 段：

| 步 | 动作 | 实测 |
|---|---|---|
| 1 | 跑 `check138` 存基线 | exit 0，PASS=22 |
| 2 | 临时往 `SUITES` 塞探针套件（`D:\_tmp\probe146.py`，5 个 `check`） | 文件 **144→145**（Δ+1） |
| 3 | 独立重算调用数 | **6319→6324**（Δ+5） |
| 4 | 再跑 `check138`，逐行比 | **0 行不同** |
| 5 | `finally` 还原 `run_all.py` + 删探针 | sha1 一致 |

**输入数真的动了，输出真的没动。**

负控制（成对）：用**旧形状**把改前改后的两个数各渲染一遍 ⇒ 两行**必然不同**（2/2）。
否则"输出没变"就不是修好了，而是**夹具没生效** —— `mutate146 M4` 把 `_insert_probe` 改成
no-op 时 `B1/B2/B4` 当场红，证明这道防线真的在挡。

## 4 判据自己的坑（本轮踩了三个，全是自找的）

### 4.1 按名字匹配 ⇒ 误报 13/15

第一版 `fam_scan` 找"输出位里出现 `_targets`/`_n_calls`/`SUITES`" ⇒ 抓到 15 处，
其中 **13 处是误报**：`check90/91/92/99` 的 `_n_calls` 是**它们自己的记账计数器**
（判据 `CALLS == PASS + FAIL`），跟套件数毫无关系。

> **提到名字 ≠ 会变** —— 这是"提到名字＝恒真"的那一族的反面，同样致命。

⇒ 改成**文件内数据流**：只有从 `_suite_scripts()` / `SUITES` 派生的量才算。
`check138` 的链路四跳：`_targets = [p for p in _suite_scripts() …]` → `for _p in _targets`
→ `_tree = ast.parse(_read(_p))` → `_n_calls += sum(…_tree…)`，跑到不动点。

### 4.2 漏了最常见的累加形态

第一版只追"值里出现脏名字"的 `+=` ⇒ `for p in _targets: _n += 1`（值是常数 `1`）追不到。
`check146 C5` 正控制只抓到 **1/2** 处才暴露。补规则：**遍历扫描集的循环体里，任何 `+=`
的计数目标都是规模量**。

### 4.3 又写了恒真判据（本轮第 2、3 次）

- `check146 E5` 第一版写成 `check(..., u'Δfiles' in src **or True**)`；
- `recheck146_core` 里两处 `check(u'…语法通过', True)` / `check(u'…合法 UTF-8', True)`。

三处**都被自己的闸抓住**（`E1` / `H12`+`H13`）。恒真比不写还危险 —— 这句话又验了一次。

## 7 豁免桶：不静默放过
