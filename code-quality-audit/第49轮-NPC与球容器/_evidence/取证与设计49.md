## 1. ★ 用户说的「球」= 第3章扭蛋球（`spr_dw_tv_gachaball_transparent`）

用户原话：「第3章里出现过一很多扭蛋的那个球」。
**排除项**：`obj_ch3_ballcon`（`spr_ballcon`）经反编译确认是**对话气泡框**
（`balloon container`：画四角 `spr_ch3_ballcon_corner` + 边线 + 角色头像 `spr_ch3_ballcon_charface`
+ 打字机 `obj_writer`），**不是球**。

**命中项**：`obj_tenna_board4_gacha` / `obj_ch3_GSC07_gacha`
（用 `spr_dw_tv_gachaball_transparent` 把角色**罩进球里**）。其 `Draw_0` 的绘制序即需求答案：

```gml
// ch3.obj_tenna_board4_gacha_Draw_0.gml（逐字）
draw_sprite_ext(spr_dw_tv_gachaball_transparent, 2, ball_bottom_pos_x, ..., ball_angle, c_white, ball_alpha);  // ① 球·下半后层
draw_sprite_ext(actor_sprite, actor_target.image_index, actor_target.x, actor_target.y, 2, 2, 0, ..., 1);      // ② ★ 角色
draw_sprite_ext(spr_dw_tv_gachaball_transparent, 3, ball_bottom_pos_x, ..., ball_angle, c_white, ball_alpha);  // ③ 球·下半前层（遮角色）
draw_sprite_ext(spr_dw_tv_gachaball_transparent, 1, ball_top_pos_x,    ..., ball_angle, c_white, ball_alpha);  // ④ 球·上罩（遮角色）
```

⇒ **「不可见处遮住角色、可见处透出角色」= 把球切成 后层 / 角色 / 前层+上罩 三段绘制**，
不需要额外的 mask；不透明像素自然遮挡。
（原作另有 `scr_draw_in_mask` / `scr_maskdraw_start,end` / `chromakey_mask_begin,end`
/ `scr_draw_mask_reset`（ch2/ch3，alpha 模板法：`gpu_set_colorwriteenable(false,false,false,true)`
+ `bm_dest_alpha/bm_inv_dest_alpha` + alphatest）——本轮**不需要**，留作精细遮罩的备选。）

### 1.2 数值（逐字取自 `obj_tenna_board4_gacha_{Create,Step,Draw}_0` / `obj_ch3_GSC07_gacha_*`）
| 量 | 值 |
|---|---|
| `_scale` | **1.55**（Susie 特例 **2.02**，`actor_target == 1411`）|
| `target_angle` | **-100**（mode 3/4）、**-150**（默认）、**-180**（mode 2）|
| `ball_alpha` lerp | 0 → 1，**5** 步（`scr_lerpvar`）|
| `ball_top/bottom_pos_*` lerp | 位移 **12** 步、**3** 次/帧、缓动 `"out"` |
| `ball_angle` 延迟 | `scr_script_delayed(..., 6, "ball_angle", ..., 15, -1, "out")` = **延迟 6 帧、历时 15 帧** |
| 角色缩放 | `draw_sprite_ext(..., 2, 2, 0, ...)` = **2×** |
| 上下半偏移 | `y_offset = 28`、起始 `109 / 221` ⇒ 上半 y=109、下半 y=221（相距 112）|
