中文 token 换算率实测 · 2026-09-20
================================================================
模型 : ralsei:v3
方法 : /api/chat 发已知字数的中文串，读回 prompt_eval_count（含对话模板开销）

体裁              字符数     token数    字/token
--------------------------------------------
口语闲聊             67         49      1.367
设定复述            120         89      1.348
追忆往事            117         86      1.360

平均：1 token ≈ 1.359 个中文字

— 用它复核 AI_REPLY_MAX_CHARS —
num_predict = 256 token  →  物理上限 ≈ 348 字
AI_REPLY_MAX_CHARS = 220  →  占物理上限 63%
（设计目标：落在 50%%~75%% —— 保住"正常的 3~4 句"，砍掉真正的跑飞）

⚠️ 注意：prompt_eval_count 含对话模板开销（几十 token 的固定前缀），
   所以真实"每个字"的比率会比这里**略高**（分母被抬大了）。
   换句话说：这里的估算偏向保守，实际能吃下的中文字数只多不少。
