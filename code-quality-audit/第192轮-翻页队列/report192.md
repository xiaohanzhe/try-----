# 第192轮 · 翻页队列（一框一条）

> 日期：2026-11-16
> 分支：`local-192`
> 用户口径：`原作不就是一句话一个框吗，按原作` ＋ `有些没有表情的那就用旁白`

---

## 1. 这一轮做了什么

对话框从"**往下堆**"改成"**一页一条**"：框里只摆当前这一条，多条排队；旁白与台词**各占一页**。

| 项 | 结果 |
|---|---|
| 产品改动 | `modules/dialogue_ui.py` 新增翻页队列（`_pages` / `_page_idx` / `_typing_page` / `_hist_synced` + 9 个方法） |
| 触发方式 | 单击 / 输入框为空时回车 / 打字结束后静置 2 秒 |
| 判据 | `check192.py` **38 条**全绿 |
| 变异 | `mutate192.py` **25/25 全抓**（含 1 条无害变异断言红 0） |
| 全量回归 | 见 §7 |

## 2. 为什么是"双轨"而不是"把历史改成当前页"

第一版想法是让 `_history_html` 直接变成当前页 —— 最省事，但**会被三条既有判据同时否掉**：

| 判据 | 形态 | 冲突点 |
|---|---|---|
| `check52a` A2a / A2b | 静态 AST | 要求 `add_dialogue` / `_maybe_break_turn` 里看得见 `self._history_html = ...` |
| `e2e_narr190` | 运行期 | 按 `_history_html` 内容切片对账 |
| `dialog_turn52` H4b | 运行期 | 跨轮让位后 `hist` 必须为空 |

于是改成：

```
_history_html  ←  "全部已完成消息"的拼接（存了什么，一个字不变）
_pages         ←  逐页列表
_page_idx      ←  画第几页
```

**唯一改变的是"画哪一页"。** 这也是为什么 190 个老套件里只有 6 条 DIFF、且全是行号回显。

## 3. 三个"看起来对、其实会坏"的坑

### 3.1 历史区不能提前写

打字中的那一句必须占一页（否则旁白排在它前面时翻不到），但**不能提前进 `_history_html`**。

我第一次实现就是提前写的 —— `dialog_turn52` **H4b** 的回显直接把它摆出来（跨轮让位后 `hist` 不是空）。
修法：`_hist_synced` 计数 + `_sync_typing_page_into_history()`，**只在 commit 时**调。
`check192 C4` 用 AST 枚举调用者，多一处就红。

### 3.2 旁白会被前台永久顶掉

第190轮为了让"上一句 + 正在打的一句"两行消失，把渲染规则定成"前台独占"。
于是 Ralsei 分支若「先 `_start_typing` 再 push 旁白」，**旁白永远看不见**。

三件事缺一不可：

1. `_typing_page` 记"前台那一句是第几页"；`_typing_own_page()` 判"游标是否还没走到它"；
2. `_refresh_display` 三分支（只画那页 / 前台独占 / 老路径叠加）；
3. **旁白排在 `_start_typing` 之前** —— 反过来台词页下标更小，视觉就变成"先说话后做动作"。

### 3.3 绝不跳页

新页到达时把游标设成末页，"同一拍三连"（结算 → 统计 → 道谢）会跳过中间那句。
`advance_page()` 一次只 `+1`；`_push_page` / `_arm_page_timer` **不许碰**游标。

### 3.4 附带：打字页延后开打

旁白排在台词前面时，那 2 秒停留会在打字机还在跑时白白消耗 —— 用户真看到那一页时字早打完了。
所以 `_start_typing` 发现"前面还有没翻完的页"就**先不打**，等游标走到再开。

**副作用（如实记）**：新消息到达后光标要等旁白翻完才闪。

## 4. 三处触发

| 触发 | 落点 | 细节 |
|---|---|---|
| 单击 | `mouseReleaseEvent` | `stop_typing()` 先 → `advance_page()` 后 → 聚焦输入框最后；**只有真翻成功才 return** |
| 空回车 | `eventFilter` | 原来是 **no-op**（`send_message` 开头就 return），现在接到翻页 |
| 静置 | `_page_timer` | `PAGE_DWELL_MS = 2000`，singleShot，**有积压才起**，打字期间不起 |

★ **`Z` 键不用** —— 与 R5 附身抢同一个键。`A6` 扫全模块的 `Key_Z` 与 `'Z'` 字面量，必须零命中。
