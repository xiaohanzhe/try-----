多跳可达性受控实验：代码 —(熬夜)— 咖啡（代码与咖啡从未同句）
============================================================================

  句子 A = 写代码写到熬夜了
  句子 B = 熬夜就靠咖啡撑着
  A 的关键词 = 代码 到熬 到熬夜 熬夜
  B 的关键词 = 熬夜 靠咖 靠咖啡 咖啡 咖啡撑 啡撑

  拓扑      阶段       熬夜边(其一)        「咖啡」是否被联想起来
  ----------------------------------------------------------------------
  clique  stage1 x1 weak|n=1       no
  clique  stage2 x2 mid|n=2        YES  hops=2 score=0.1238
            代码 → 熬夜 → 咖啡
  clique  stage3 x3 strong|n=3     YES  hops=2 score=0.3196
            代码 → 熬夜 → 咖啡

  star    stage1 x1 weak|n=1       no
  star    stage2 x2 mid|n=2        no
  star    stage3 x3 strong|n=3     no

  chain   stage1 x1 weak|n=1       no
  chain   stage2 x2 mid|n=2        no
  chain   stage3 x3 strong|n=3     no

  ----------------------------------------------------------------------
  判定（stage1 必须 no，stage2 必须 YES）：
    clique  [False, True, True]  → PASS
    star    [False, False, False]  → FAIL
    chain   [False, False, False]  → FAIL
