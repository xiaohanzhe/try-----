## 2. 原作的「幽灵可见性」到底怎么实现的（`_evidence/gml64/`，逐字反编译）

### 2.1 跟着主角飘：`obj_ghostbuds` 的 `Draw_0`

```gml
// 位置 = 相对主角（Chara 在左、Clover 在右）
draw_sprite_ext(charasprite, charaface, (obj_mainchara.x - 20) + tcharax,
                (obj_mainchara.y - 20 - levitate) + tcharay, 1, 1, tchara_angle, c_white, chara_alpha);
draw_sprite_ext(cloversprite, cloverface,  obj_mainchara.x + 20 + cloverx,
                (obj_mainchara.y - 20) + levitate + clovery, 1, 1, clover_angle, c_white, clover_alpha);
```

- **左右 ±20 px**，随主角移动；`levitate` 是上下浮动（±2.5~3，配合 `alarm[4]` 随机换向）。
- 颜色常量固定 `c_white` ⇒ **幽灵感完全来自 alpha，不是调色**。

### 2.2 可见性 = 「主角停不停」＋「幽灵的亮度档」

```gml
if (obj_mainchara.moving == 0)            // ★ 主角站住
{
    if ((clover_alpha < 0.9 && juandice > 0) || (clover_alpha < 0.6 && juandice == -1))
        clover_alpha += 0.05;              //   幽灵渐渐显形（0.9 = 亮档 / 0.6 = 暗档）
    if ((car > 0 && chara_alpha < 0.9) || (car == -1 && chara_alpha < 0.6))
        chara_alpha += 0.05;
    ...
}
if (obj_mainchara.moving == 1)            // ★ 主角一走动
{
    clover_alpha -= 0.05;                  //   幽灵每帧淡出
    chara_alpha -= 0.05;
}
if (clover_alpha <= 0 && chara_alpha <= 0) // 都淡没了 ⇒ 自己销毁
{
    obj_mainchara.ghosttimer = 0;
    instance_destroy();
}
```

⇒ **原作的规则是「你停下来才看得见幽灵，一走动它们就消失」**（每帧 ±0.05，约 18 帧 ≈ 0.6 s）。
两条档位：**0.9 = 亮（"主"幽灵）／0.6 = 暗（陪衬幽灵）**；在特定遮挡物附近还会降到 0.5/0.3。

### 2.3 ★★ 谁能"看得见"：`juandice` / `car` 与 **LV（`scr_murderlv()`）**

```gml
if (instance_exists(obj_face_chara))
{
    ... 由 Chara 的表情决定 charaface（0~7） ...
    if (scr_murderlv() < 12)   // ★★ LV < 12 时，另一只（Clover）被压成暗档
        juandice = -1;
    car = 1;                   //    Chara 走亮档
}
else if (instance_exists(obj_face_clover))
{
    ... Clover 的表情决定 cloverface ...
    juandice = 1;              //    Clover 走亮档
    car = -1;                  //    Chara 走暗档
}
```

- **同一时刻只有一只是"亮"的**（谁有 `obj_face_*` 谁亮），另一只降到 0.6 暗档。
- **亮/暗与 `scr_murderlv()`（LV = 等级 = 杀戮值）挂钩** ⇒
  ★ **「决心/等级越高，越能看清幽灵」在原作里是有代码出处的，不是我们自己编的。**
- 另有 `global.flag[7] == 0` 这个门槛：不满足就**不画 Clover 的幽灵**。

### 2.4 定点幽灵 `obj_ghostint2`（Chara 站在某处）

```gml
// Create_0
if (instance_exists(obj_mainchara)) if (obj_mainchara.kill == 1) instance_destroy();  // ★ kill 标记 ⇒ 不出现
if (room == room_area1 && global.flag[19] > 0) instance_destroy();
image_speed = 0;
if (room == room_area1) { sprite_index = spr_ghost_chara_lean; image_xscale = -1; }   // 靠墙"倚着"
if (room == room_fire_restaurant) if (!instance_exists(obj_sansdate3)) instance_destroy();
if (room == room_fire_finalelevator) sprite_index = spr_ghost_chara_lean;
```

```gml
// Step_1 —— ★ 按「离主角多远」决定可见度
dist = distance_to_object(obj_mainchara);
...
else if (dist < 100)
{
    disto = 10 / (dist + 1);        //   越近越清楚
    if (disto > 0.9) disto = 0.9;   //   上限 0.9
    image_alpha = disto;
}
else if (image_alpha > 0) image_alpha -= 0.05;   // 走远了就淡出
```

- **`dist < 100` 才开始显形，且 `alpha = min(10/(dist+1), 0.9)`**（距离反比、封顶 0.9）。
- 上下浮动：`y ± 0.1`，范围 `starty ± 2`。
- **表情帧由 `obj_face_chara` 的当前表情映射**（annoy/confused→1、surprised/shock→2、
  right/posh→3、up/left_upset/sad→4、cheer/lookside_smile/smirk/smug/cheeky/edgeworth→5、
  panic/squint_upset→6、creep→7、其余→0）⇒ `spr_ghost_chara_down` 的 **8 帧就是 8 种表情**。

### 2.5 幽灵说什么：`scr_ghosttalk`

开头就是按**杀戮数/等级**分支：

```gml
clover = 1;  if (global.flag[7] == 1) clover = 0;
if (obj_mainchara.kill == 1) clover = -1;
irememberyourneutrals = 0;  if (global.kills > 10) ... > 20 ... > 30 ... > 40 ... > 50 ...
```

⇒ 幽灵的台词**记得你杀了多少**（每 10 杀升一档）。这跟 §2.3 是同一套「决心/杀戮」轴。

## 3. 对「Chara = 幽灵，只有决心强的人能看到，Ralsei 是特例」有什么用

| 用户的规则 | 原作里已有的对应物（可直接照抄的那部分） | 必须由我们自创的那部分 |
|---|---|---|
| 幽灵形态 | `spr_ghost_chara_*`（已抽取入库，45 个 PNG） | — |
| 「看得见」 | alpha 由**距离**（`dist<100`、`min(10/(dist+1),0.9)`）与**主角是否移动**驱动 | — |
| 「决心强才看得见」 | `scr_murderlv()`（LV）决定亮档/暗档；`global.flag[7]` 决定画不画 | 「决心」在这个桌宠里**没有 LV 可读** ⇒ 需要一个替代量（建议：Ralsei 与用户的交互/信任度，或一个显式的 `determination` 档位） |
| **Ralsei 是特例** | **无**（原作里没有 Ralsei） | ★ 纯自创，必须标注 |

★ 结论：**「只有决心强的人能看到幽灵」这句在原作里有真实出处**（LV/杀戮轴），
所以这不是硬塞的设定；但「Ralsei 是特例」是**本项目扩展**，要在人设与代码里明确标注。
