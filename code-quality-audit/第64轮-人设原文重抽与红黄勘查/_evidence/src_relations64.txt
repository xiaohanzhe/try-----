以下按你前面给出的设定整理，含剧透。整体上，这些人物不是孤立关系，而是围绕几条核心关系网：Dreemurr 家的破碎家庭、英雄小队的三角关系、纸牌王国的扭曲家庭、学校里的暗恋与竞争、以及被遗忘者与被守护者的情感线。

一、光世界：Dreemurr 家与 Holiday 家

Toriel 与 Asgore 曾是夫妻，现在是离婚状态。Kris 和 Asriel 是他们的孩子，Kris 是养子，Asriel 已去上大学。Toriel 对 Asgore 保持冷淡边界，Asgore 仍深爱 Toriel，却只能用花店、旧回忆和笨拙的关心表达。Kris 是连接双方的孩子，但沉默寡言，不擅长表达对任何一方的情感。Asgore 的花店里有一束特别的金色花——也就是后来的 Flowery。Flowery 在暗世界成为 Asgore 的保护者，因此它与 Toriel 也有间接联系：它本是 Asgore 求婚花束的一部分。

Noelle 来自 Holiday 家。父亲 Rudy 住院，母亲 Carol 是市长，姐姐 Dess 已不在。Noelle 与 Kris 是童年邻居和朋友，Kris 小时候常吓她，她却不完全讨厌那种被关注的感觉。Noelle 暗恋 Susie，同时害怕 Susie；Berdly 是她的学习搭档和分组报告组员，Berdly 自以为 Noelle 喜欢他，但 Noelle 并不喜欢他的自大。Berdly 后来表示自己也迷恋 Susie，这直接激怒了 Noelle。学校线里，Toriel 是老师/学校创办者，Alphys 是现任老师，Gerson 是前任教师，Berdly、Noelle、Kris 都是同学。

二、英雄小队：Kris、Susie、Ralsei

Kris 是队伍的核心，也是连接光世界与暗世界的关键。Susie 是 Kris 最重要的搭档，两人从同学变成真正的伙伴；Kris 对 Susie 有深厚信任，会主动保护她。Ralsei 对 Kris 极度依赖和忠诚，把 Kris 视为最重要的朋友，但 Kris 对 Ralsei 保持距离，不算热络，甚至有些冷淡。Susie 与 Ralsei 的关系从“嫌他啰嗦软弱”逐渐变成“嘴硬心软地保护他”。三人构成一个不平衡的三角：Kris 与 Susie 更亲近，Ralsei 渴望靠近 Kris，Susie 则在中间成为情感缓冲。

三、纸牌王国：King、Queen、Lancer、Rouxls

Lancer 是 King 的儿子。King 是暴君式的父亲，忽视 Lancer，甚至把他当人质；Lancer 崇拜过父亲，但最终选择朋友，背叛 King 的立场。Queen 与 King 有过旧关系，后来成为 Lancer 的“女爸爸”，会去监狱羞辱 King，并接管照顾 Lancer。Rouxls Kaard 是 Lancer 的“小爸爸”，实际照顾他最多，虽然嘴上抱怨，却会做饭、陪伴、保护。于是 Lancer 拥有一个非常扭曲但完整的“家庭”：父亲 King、女爸爸 Queen、小爸爸 Rouxls。Lancer 与 Susie 是最好的朋友，他崇拜 Susie，把她当成第一个真正的朋友；与 Kris、Ralsei 也是朋友。King 是英雄小队的敌人，Queen 则从对手变成休战对象，Rouxls 是反复横跳的亦敌亦友。

四、赛博世界与电视世界

Queen 统治赛博世界，把 Berdly 当棋子，却真心相信 Noelle 很强大，想让 Noelle“选择让自己快乐的世界”。Berdly 则误以为 Queen 重视自己。Noelle 被 Queen 绑架，但 Queen 对她并非纯粹恶意，而是一种扭曲的关心。Berdly 与 Kris 是同学和游戏竞争对手，与 Susie 从鄙视到迷恋，与 Noelle 是学习搭档却从不真正理解她。

Tenna 是 Dreemurr 家客厅里的旧电视，曾在光世界陪伴过 Kris 一家，如今被遗忘。它渴望被观看，与 Kris 有旧家庭纽带，与 Susie 的关系是转折点：Susie 认真告诉它“你会找到一个家”。Ralsei 是它节目里的嘉宾。Tenna 与 Spamton 曾是商业伙伴，后来成为宿敌。Rouxls 在第三章试图为 Tenna 服务，延续他“站在赢家一边”的生存策略。

五、第四章与第五章：Gerson 与 Flowery

Gerson 在光世界已经去世，是 Alvin 神父的父亲、小镇历史学家和前任教师。在第四章暗世界中，他作为“老爷子”和“正义之锤”出现，成为 Susie 的精神导师。他看出 Susie 握着“希望”，鼓励她写自己的故事。他与 Kris、Ralsei 也保持长辈式的友好。他对 Alvin 的爱深沉却笨拙，留下信件，却没能亲口说出骄傲。

Flowery 是 Asgore 求婚花束中的金色花，在暗世界获得人形。它唯一的行动核心就是保护 Asgore，因此它与 Toriel 有间接的象征联系，与 Asgore 是“被照料者反过来守护照料者”的关系。它对 Ralsei 充满敌意，强行把他赶出队伍、贬低他、让他穿旧衣服，但深层原因是它看不惯 Ralsei 被“角色”困住，想把他从自卑的壳里逼出来——方式却很粗暴。它称 Susie 为“公主”，认可她身上那种不被定义的自由；它提醒 Kris 要对 Ralsei 友善。它和《Undertale》的 Flowey 不是同一个存在。

六、总体关系网

如果画成图，Kris 和 Susie 是两个连接点。Kris 连接着 Dreemurr 家、Toriel/Asgore、Noelle 的童年、黑暗世界英雄队、Tenna 的旧电视记忆、以及 Asgore 花店里的 Flowery。Susie 连接着学校、Lancer 的友情、Ralsei 的成长、Noelle 的暗恋、Berdly 的迷恋、Toriel 的照顾、Gerson 的师徒关系，以及 Flowery 的认可。

这些关系共同指向几个主题：家庭可以破碎，也可以重组；孤独的人会寻找观众、朋友或守护对象；温柔与控制常常纠缠；被遗忘者仍在等待被看见。 而 Ralsei、Susie、Kris、Lancer、Noelle、Berdly、Tenna、Flowery、Gerson 这些人，都在用自己的方式回答同一个问题：当世界不按预言走时，你还要不要写自己的故事。
