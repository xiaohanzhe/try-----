NPC 说话时「动一下」的三种演法

用的都是 真实素材：hy_axis 的表情头像 + 他自己的四帧走路图（spr_axis_down_0..3.png）。 三块同时自动循环，也可以点「播放」单独看一遍。差别只有两点：本体占不占位置、表情会不会被顶掉。

A

头像下加小本体位

表情全程都在。代价：整个框会高一点（多出一行本体的高度）。

AXIS
系统状态正常。你要问的事，我这边有记录。
静息
B

头像框临时换成本体

不改布局、框不变高。代价：那一瞬看不到表情，脸→小人→脸会闪。

AXIS
系统状态正常。你要问的事，我这边有记录。
静息
C

只让头像框轻轻一顿

最保守：不加位置、不用走路帧。代价：严格说这不算角色动画。

AXIS
系统状态正常。你要问的事，我这边有记录。
静息

查盘时看到的一个实情：素材命名不统一 —— hy/dalv_down_0.png、ut/spr_alphys_d_0.png、 ot/iocAsgoreDown_0.png 三种写法都有，所以取帧不能拼一个格式，得按角色扫盘解析； 找不到帧就不演、不报错（静默降级）。
