## §2 病是什么

`first_sentence()` 原来的切点逻辑是**按标点类型优先级**挑的：

```python
for sep in ('。', '！', '？', '!', '?', '\n'):
    if sep in t:
        chosen = sep
        break
i = t.index(chosen)
t = t[:i + 1]
```

它问的是"**有没有句号**"，而不是"**最靠前的句末标点在哪**"。
所以只要文里出现过句号，切点就被钉在**第一个句号**上 —— 哪怕更前面早就有一个问号。

真机样本（第131轮 `before/Q7#2`，`live7_131.jsonl`）：

```
raw   : 你说的是坏消息吗？\n\n你说的是坏消息的时候我不该用亮起来的开头，
        先就着那件具体的事问一句。\n\n**你今天下班有点晚，是怎么回事啊……我在。**
old   : 你说的是坏消息吗？\n\n你说的是坏消息的时候我不该      ← 24 字，断在"我不该"
new   : 你说的是坏消息吗？                                    ← 9 字，完整
```

`#Q7#3` 同型（断在"先就着"）。

★ 这两条**四道闸都拦不住**（第133轮已实测 3/3 不命中）⇒ 它们会**原样显示在气泡里**。
这就是"吊尾巴"的用户可见后果：一句话说到一半就没了。

## §3 修法：不是"取最靠前的标点"

### §3.1 第一版（错）

我第一版把规则改成"把所有句末标点按位置排序，取第一个够长的切点"。看着更自然，但
`s7_event_speech A11` **当场判红**：

```
[FAIL] A11 first_sentence 与 start_autonomous_speech 同口径：优先句号（一个完整的想法）
       <<< 诶？！好舒服呀。后面还有好多话要说呢。
```

它把这条**整句**留下了（21 字），而契约要求切成 `诶？！好舒服呀。`。

红得对。`A11` 守的是"**句号 = 一个想法结束了**"这条语义：
- `诶？！好舒服呀。后面还有好多话要说呢。` ⇒ 后半句是**新话题**，该切；
- `哎呀！别捏我的耳朵！好痒呀！` ⇒ 三连感叹是**同一股劲**，整句留才对。

"取最靠前"分不出这两者 —— 它只看位置，不看"哪一类标点才算想法结束"。

### §3.2 最终（三条分支，每支都有东西撑着）

```
① 有句号 ⇒ 只在"句号及之前"的切点里挑第一个够长的；都不够长就用句号本身
② 没句号 ⇒ 只看**第一个**句末标点：够长就切，太短就整句保留
③ 没句号 + 太短 + 全文超上限 ⇒ 切（保持改造前行为，不在这里发明新策略）
```

逐条验：

| 输入 | 走哪支 | 输出 | 依据 |
|---|---|---|---|
| `你说的是坏消息吗？…我不该…` | ① | `你说的是坏消息吗？` | 本轮要修的 |
| `诶？！好舒服呀。后面还有…` | ① | `诶？！好舒服呀。` | `A11` 既有契约 |
| `诶？！听到这话…起来了。感觉…` | ① | `诶？！听到这话…起来了。` | `A9` 既有契约 |
| `谢谢你，小豆。让我靠你一会儿。` | ① | `谢谢你，小豆。` | `A9` |
| `哎呀！别捏我的耳朵！好痒呀！` | ② | 整句 | `A9`（三个短感叹是一句） |
| `嗯？发生了什么吗？` | ② | 整句 | `MIN_FIRST_CHARS` 的实测起因 |
| `嘿嘿~ 好舒服呀！谢谢你主人！` | ② | `嘿嘿~ 好舒服呀！` | `A9` |

`MIN_FIRST_CHARS = 6` 的原始语义**原样保住**（它落在分支②的"太短就整句保留"上）。

## §4 自纠 2 处

### §4.1 产品侧：第一版被既有判据抓回（见 §3.1）

值得单独记的不是"我改对了"，而是：**这次是判据先开口，我才发现自己丢了契约**。
上一轮（134）刚记过"判据自己错"的教训，这一轮反过来 —— **既有判据抓到了产品的真回归**。
两条加起来才是完整的：判据会错，也会对；关键是每次都回去看它守的是什么。

### §4.2 判据侧：`A1n` 正控制的方向写反了

第一版：

```python
_mut['raw'] = raw + '。多出来的一句。'      # 往末尾加
check(...  ES.first_sentence(_mut['raw']) != first)   # 期望"变了"
```

跑出来红。**红的是判据**：`first_sentence` 只取第一句，往**末尾**加东西本来就不影响结果
⇒ 负控制的输入没落进被测分支（第129/133轮那条教训的同型）。
改成在**开头**加 `我先说一句。` ⇒ 输出立刻变成 `我先说一句。`，判据才有鉴别力。

★ 顺带记下一条通用形状：**给"截断/取前 N"类函数做变异，要动开头，不要动结尾。**
