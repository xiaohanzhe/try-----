## 二、施工口径：只搬方法、不搬状态（Wave 1 铁律）

状态仍留在宿主，控制器通过 `__setattr__` / `__getattr__` 转发。

### 两类白名单改写（均带命中计数断言）

| 类型 | 判据 | 本项命中 |
|---|---|---|
| `__setattr__` 转发 | "宿主**已拥有**该名字" | 12 个 `_hide_*` 状态字段 |
| `__getattr__` 回落 | ① 宿主属性 ② 兄弟控制器 ③ 路由表的宿主属性 | 见下 |

`__getattr__` 的**第 3 条白名单**（兄弟控制器）在本项**不可省**：
`_hide_on_arrive_center` 要调 `self._cast_spell_then`（属 **W1-1 `spell`**），
`_hide_end_game` / `_hide_report_clicked_folder` 要调 `_hide_destroy_obstacles`（本类）。

实现 = **复刻宿主 `_CONTROLLER_ATTRS` 扫描**，`skip self`：

```python
for _attr in getattr(type(pet), '_CONTROLLER_ATTRS', ()):
    _ctrl = pet.__dict__.get(_attr)
    if _ctrl is None or _ctrl is self:
        continue
    if getattr(type(_ctrl), name, None) is not None:
        return getattr(_ctrl, name)
raise AttributeError(name)
```

> **注意**：`__setattr__` 必须**跳过 `'p'`** —— 控制器自己的 `self.p = pet` 是构造期
> 内部状态，若也走"宿主有没有 `p`"的判据会错判（W1-4 已踩）。

## 三、踩坑记录

### 坑 1：分组器误纳 `_hide_ralsei`（见第一节，施工前拦截）

### 坑 2：`_log_` 是**实例方法**，机械改写会产出裸调用 → `NameError`（★P0，铁律 6）

`main.py` 里这 12 个方法用的是**模块级 logger** `_log.debug(...)`。
搬进控制器后，控制器模块自己**没有** `_log` 这个模块级名字（只有 `_log_()` 方法）。
若把 `_log.` 机械替换成 `_log_().`（**少了 `self.`**）：

- 语法合法、编译通过、import 通过；
- 只有**真的走到那个 `except` 分支**才炸 `NameError`；
- 而正常路径根本不进 `except` —— **P0 会被完整地藏起来**。

本项由 `A/B AB12d` 专门守住：故意造"去掉 `self.`"的坏版本，
断言它在探针的默认命名空间下**当场 `NameError`**（且错误文本点名 `_log_`）。

### 坑 3：`os.` / `time.` 是 **Attribute 根，不是 Name-func**（铁律 8）

侦察脚本只扫"裸 `Call` 的 `func` 是 `Name`"，因此**完全没看见** `os.`/`time.` 这类
"裸 Attribute 根"。本项 `import os` 在控制器里已是模块级（沿用），但 `import time`
是**新加**的 —— 若漏了它，`time.time()` 会在 `_hide_on_arrive_folder` 里
`NameError`，同样只在真实路径暴露。

### 坑 4：`QTimer(self)` → `QTimer(self.p)`（铁律 1）

`main.py` 里 `self` 是 `RalseiPet`（`QWidget`，是 `QObject`）→ `QTimer(self)` 合法。
搬进控制器后 `self` 是**纯 `object`** → `QTimer(self)` 抛
`TypeError: arguments did not match any overloaded call`。

**这是本项唯一一处铁律 1，且 100% 测不出"逐字等价"。**
详见第五节"鉴别力边界"。

### 坑 5（探针坑，代价最大）：A/B 探针本项**五次迭代**才归零

失败数轨迹：`63/9 → 69/9 → 73/6 → 75/5 → **82/0**`。

#### 5.1 夹具"噪声"混进信号：绝对路径含自增序号（3 项假红）

沙箱目录用 `mkfolder(tag)` 建，名字是 `ab7_win_20` —— **序号就在目录名里**。
于是 `os.path.basename()` **抹不掉**它，A 跑得 `ab7_win_20`、B 跑得 `ab7_win_23`：

```
AB7.clicked 事件序列一致 ::
  old=[('open_folder', 'ab7_win_20'), ('show_win', None), ('resolve_anchor', 'ab7_win_20'), ...]
  new=[('open_folder', 'ab7_win_23'), ('show_win', None), ('resolve_anchor', 'ab7_win_23'), ...]
```

看着像行为差异，其实是**"两侧各建了一遍夹具"**。

**修法**：加**稳定逻辑名登记表** `_STABLE`（绝对路径 → tag），
`mkfolder` 顺手登记，`stable_name()` **精确查表**归一（不靠正则猜）。
输出变成 `('<ab7_win>')`，两侧恒等。

#### 5.4 ★★ A/B 形态**结构性地屏蔽了铁律 1**（本项最重要的方法论发现）

AB12b 反控（把 `QTimer(self.p)` 回退成 `QTimer(self)`）**预期能抓到差异**，
实测 `parents == ['Stub']` —— **坏版本也"通过"**。

根因：本探针的"方法体搬迁"形态是 `types.MethodType(fn, stub)`，
方法体内的 **`self` 就是 stub（宿主）**。
所以 `QTimer(self)` 与 `QTimer(self.p)` **传的是同一个对象**。

> ⇒ **A/B 对铁律 1 的鉴别力 = 0**。它验的是"行为等价"，不是"落点正确"。
> ⇒ 铁律 1 只能由 **e2e（真控制器实例）** 覆盖 —— 见 `verify_w1_2_e2e.py` E6
>   （断言 `t.parent() is pet6`）。

AB12b 已**改写为显式断言+文档化这条边界**，而不是假装它覆盖了。
（与 W1-1 §6.4「A、B 都失败时'结果相同'同样成立」同源，但这是**第三种**成因：
不是"都没跑到"，而是"**跑了但落点被抹平**"。）

#### 5.5 ★ 反控自己也会是假的：夹具兜底掩盖了坏版本（2 项假红）

反控 2 造了"把 `self._log_().` 改成裸 `_log_().`"的坏版本，结果：
① 选错场景（`mode='play'` 下那行根本执行不到）；
② **前提写错**：我以为夹具注入的模块级 `_log` 会给裸 `_log_()` 兜底 ——
   但 **`_log` 和 `_log_` 是两个不同的名字**（前者是 logger 对象，后者是方法名）。
③ `no_log_ns` 开关用错对象：撤掉它把**正常版本也一起炸了**。

**修法**：换到"必然命中 `_log_()`"的场景（窗口扫描块抛异常），
默认 ns 下**只换被测源码**，并加 `AB12f` 证明好版本**真的执行到了那行**：

```
AB12d 坏版本 → NameError: name '_log_' is not defined   [探针有鉴别力]
AB12e 好版本 → err=None                                  [对照]
AB12f 好版本 → log_called=True                           [★证明非空跑]
AB12g 两者 stage 相同 → 差异确实来自那一行               [★定位到行]
```

> `AB12f` 这条哨兵是必须的：没有它，`AB12e` 的"正常"可能只是"压根没跑到"，
> 反控就成了**自我安慰**。

### 5.6 坑 5 暴露的**通用规律**（第 3 次补强）

W1-1 §6.4 已立：「**A 和 B 结果相同**，在 A、B 都失败时同样成立」。
本项补齐了**另外两个变体**，三条合起来构成 A/B 探针的完整失效谱：

| # | 失效形态 | 症状 | 哨兵 |
|---|---|---|---|
| 1 | 两侧都**没跑到** | 轨迹全同，全绿 | 「真的跑到了（非空跑）」 |
| 2 | 两侧都**抛同一个异常** | 轨迹全同，全绿 | 「两侧均无异常」 |
| 3 | **跑了但落点被探针形态抹平**（本项新增） | 轨迹全同，全绿，**连异常都没有** | 只能靠**换验证维度**（e2e） |

第 3 种最险：它没有任何"异常/空跑"可抓，**A/B 永远发现不了自己漏了什么**。
⇒ **口径**：A/B 只能证明"两版行为等价"，**不能**证明"改动落点正确"。
凡涉及"`self` 指谁"的改动（铁律 1/3/4/6 全是这一类），必须有**非 A/B 的独立维度**。
