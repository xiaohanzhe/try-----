## 三、铁律 7（本项的核心风险）：裸 `os.` 是 Attribute 根

**新铁律**：`os.` / `time.` / `random.` 是「**裸 Attribute 根**」，不是 `Name`-func 调用。
只扫「裸 `Call` 的 `name`」会**完全看不见它们**（W1-2 探针首跑就是这么漏的）。

本项的现场实例：

- `_open_desktop_item_by_name` 用 `os.` **15 处**（`os.path.splitext/join/exists/isdir`）；
- 但该方法体**自身没有 `import os``**；
- 父版靠 **main.py 的模块级** `import os`（L3）解析；
- 搬进新模块后 → **新模块必须有模块级 `os`**，否则只在**真正走进该分支**时才 `NameError`。

**已确认**：`file_sheet_controller.py` 模块级 = `{'logging', 'os'}`；15 处裸 `os.` 全部可解析（e2e E3/E8f 行为级 + 静态双重覆盖）。

同族记录：`local_imports = {'os', 're', 'win32com.client'}` 保持局部 —— **不提升** `win32com.client` 到模块级（会把 pywin32 变成导入期硬依赖，无 Excel 环境会崩）。
