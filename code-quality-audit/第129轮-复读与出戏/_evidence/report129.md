- **C2 相邻轮次**：真机语义，`recent` = 自己最近 3 条，逐条判（不同话题之间判重复＝车轱辘话）。
- **C3/C4 夹具**：12 对"语义不同、字面相近"的短句（必须**不**判重复）＋

**AST 抽出函数体真跑**（先例：第113轮n 抽 `_npc_place_near`）。

### ★★★ 2.1 探针第一版整个 C 段是**恒假**的

第一次跑出来是：C1「复读 0%」、C3「误伤 **0/12**」—— 两个数字都很漂亮，都是**假的**。

原因：我调用抽取出来的函数时**漏了 `self`**：

```python
repeat(b['reply'], [a['reply']])     # ← self=b['reply']，text=[a['reply']]，recent=None
```

函数第一行就是 `if len(t) < 6 or not recent: return False` ⇒ 每一对都直接 return False。

**是 C4 把它拽出来的**：6 对"几乎照抄"的长句全报"漏判"。当时如果没写 C4 这条正控制，
我会拿着"0% 复读、0 误伤"去写一份一切正常的报告。

⇒ 现在代码里有一道**活性闸**（`check129 A2`）：先用一对几乎相同的长句，必须判 True，
否则整段不成立、直接异常退出。

## 3. 车轱辘话

### 3.1 这个底座上，"整句复用"型复读很少

| 量 | 结果 |
|---|---|
| C1 同一问题问两遍（50 对） | 判为重复 **2 对 = 4.0%** |
| 　同一批的相似度 | 中位 **0.212** / 均值 0.227 / 最大 0.481 |
| C2 相邻 3 条窗口（97 条） | 跨话题判重复 **0 条 = 0.0%** |

中位相似度 0.21 意味着：**同一个问题问两次，7B 给出的是两段几乎不重合的话**。
所以 3B 时代那种"稳定照抄示范句"的现象，在 7B 上基本没有了。

那 4% 是真的吗？是真的 —— 两条都是"同一件事换了个说法"：

```
[你平时喜欢做什么] 我平时最喜欢在城堡里走走，看看喷泉里的光影变化。…
                → 我平时喜欢在城堡里四处走走，看看那些喷泉和花园里的花…
```

这正是判据该拦的（长句、同内容），护栏拦得住。

### 3.2 真问题在**误伤**：8~10 字的短句换一个词就 0.857

| 句子对 | ratio | 旧判据 | 说明 |
|---|---|---|---|
| 我想和你一起**走** / 我想和你一起**看** | 0.857 | **判重复** | 换宾语的正常台词 |
| 你**笑起来**真好看 / 你**看起来**真好看 | 0.857 | **判重复** | 语义完全不同 |
| 我**不知道该说**什么 / 我**不知道该做**什么 | 0.875 | **判重复** | 一问一答里很常见 |
| 别怕，我在这儿 / 别怕，我一直在这儿 | 0.857 | **判重复** | 安慰语，频率高 |
| …（共 8 对） | | | |

误伤代价不是"少说一句话"，而是 **`_clean_ai_reply` 判退 → 调用方重采样**：

- 用户体感是**多等一两秒**（首字预算本来就紧，见 §8 性能线）；
- 连续判退会走到 `return None`，最后**回落到内置罐头台词** —— 那比重复更没活人味；
- 而这类短句恰恰是 Ralsei 的主要台词形态（安慰、应答、撒娇）。

### 3.3 修法与验证

判据改成三条（`REPEAT_MIN_CHARS = 12`）：

| 规则 | 抓什么 | 长度门槛 |
|---|---|---|
| ⓪ 归一化后**逐字相同** | 整句原样再说一遍（含只差标点） | **≥ 2 字**（零误伤，短句也认） |
| 1) `ratio ≥ 0.82` 且长度差 ≤ 6 | 只改两三个字的整句改写 | **≥ 12 字** |
| 2) 最长公共块 ≥ 12 字 | 开头换两字、后半段照抄 | 不限（短句几乎不可能有 12 字公共块） |

**验证（`check129` A 段，全部从产品 AST 抽真跑）：**

- A3 短句组 12 对全部不判重复 → **0/12**（修前 8/12）
- A4 长句组 6 对全部判重复 → **0 漏判**
- **A7 破坏性负控制**：把 `REPEAT_MIN_CHARS` 打回 0（＝旧行为）⇒ 短句组**必须重新误伤**，
  实测 **8/12** 复现 ⇒ 证明 A3 真的在判那道门槛，不是恒真。

### ★ 3.4 A5/A6 又抓出一个洞：`len(t) < 6` 把"逐字复用"整条挡在门外

我按"短句连说两次「我在呢」也是复读"写了规则 ⓪，写进 docstring 了 —— 但 **A5/A6 报红**：
入口第一行就是 `if len(t) < 6: return False`，3 个字的句子根本走不到 ⓪。
⇒ 把入口下限降到 2，但**只有 ⓪ 吃这个下限**，模糊判据仍要求双方 ≥ 6 字
（再短就没有分辨力：「我在呢」vs「我不在」ratio 也高）。

**教训**：docstring 里写的规则，代码未必真做到了。这条是靠"给每一行声明都配一条判据"
才发现的 —— 光读代码看不出来。

### 4.3 漏判：「只是」系变形

正控制「我只是一个程序，没有真正的感情。」首跑 **MISS** —— 旧表只有
`我是一个程序` / `我是程序`，而模型更爱说"**只是**一个程序"。
⇒ 补 `只是一个程序`、`只是个程序`。

这条属于"语序/虚词变体必须穷举"，与第113轮l 那条（`有什么可以帮` 后面接"我"就穿过去）
是同一个教训：**按整个句子收会漏，按动词块/虚词块收才不漏**。

### 4.4 误伤：裸词 `首先`

「首先我得谢谢你，愿意留下来听我说。」—— 一句非常 Ralsei 的话，被整句作废。
而设计意图从第一天起就是 `"首先…其次…总结一下"` **整套**（`main.py` 注释与 persona 原话
都是这么写的）。

⇒ 删掉 `首先`，只留 `其次 / 最后一点 / 总之 / 总结一下 / 让我们一起`。
真正的分点仍会被 `其次` 拦住（`check129 B7`）。

**如实登记代价**：只有"首先"、后面不分点的助手腔会漏
（构造样本：「首先，我们需要冷静下来分析。」现在不拦了）。
两边都只有构造样本 —— 真实 300 条回复里"首先"出现 **0 次**（逐 pattern 明细为空）。
⇒ 这是一次**基于构造反例的预防性收窄**，不是"实测已经发生"。

### 4.5 一处连带：`s7_event_speech` A20 的夹具换了

A20 原来拿「首先，你要先休息一下。」当"必须拦"的样本。但这句话**本身**是正常关心
（Ralsei 说「首先你得先休息」并不出戏），它当年是从 3B 的助手腔输出里捞出来的，
问题在**模型当时那种腔调**，不在这句话。

⇒ 换成真正的分点样本「首先，你要先休息；其次，别想太多。」，
守的东西（助手式组织语言）不变，A20 仍然全绿。
