Q3. 为什么"连切换都没有"？
==========================================================================
（a）真实调用点计数（在 main.py 里）：
   scene.switch(          4 次
   follow_route           0 次
   pick_route             1 次
   plan_route_to          0 次
   resolve_destination    0 次
   destinations(          2 次

（b）scene.switch() 的**全部**调用点（去重后只有 3 个真实入口）：
   main.py:3258   return bool(self.scene.switch(scene_id))
   main.py:7397   · 场景切换复用既有 `self.scene.switch()`（不新开通道、不绕过世界门控）；
   main.py:7406   ok = bool(self.scene.switch(home))

   ⇒ 三个入口分别是：
      · 暗之泉（item_interact.FountainProp.on_interact → _item_enter_scene）
      · 睡觉回房（BEDTIME_HOME_SCENE）
      · 无（scene_controller 内部 load() 自调）
   ★ **没有任何"从桌面出发、走向某个房间"的入口。**

（c）路由能力**全都写好了，但零接线**：
   scene_controller 提供：pick_route / follow_route / plan_route_to /
                        destinations / destinations_text / resolve_destination
   而 main.py 对它们的调用：只有 pick_route 出现 1 次（在**注释**里）。

==========================================================================
Q3b. 就算站在城堡镇按 E，门也不会响应（第二层原因）
==========================================================================
item_interact.classify("obj_doorA") = {'kind': 'door', 'in_data': True, 'handled_by': 'scene_routing'}
NON_INTERACTIVE_KINDS            = frozenset({'marker'})

build_props() 的 else 分支注释原文：
   「仍不在这里实现的：door —— 交路由层（见 classify 的 handled_by）」
   ⇒ 门**不进 item_props 列表**，所以 interact_scene_prop() 遍历不到它。
   ⇒ 按 E 只会命中 savepoint / readable 等非门物件；门无响应。

==========================================================================
总结（三问三答）
==========================================================================
Q1 场景系统启动了吗？   → 启动了（1014 场景索引加载 OK）。
Q1b 但用户站在哪？     → 站在 `desktop`，一个**故意空着**的场景（bg/objects 全空）。
Q2 为什么看不到门？     → 门属于真实房间（城堡镇 3 扇：doorA/B/X，贴图齐全），
                          桌面场景本来就没有门。渲染链路是通的。
Q3 为什么切换不了？     → **没有任何通路**。三条路全断：
                         ①「走到门→切换」：无实现（门不画在桌面、且不响应 E）
                         ②「聊天说去城堡镇」：无实现（AI 侧只到 scene_id，无 switch 调用）
                         ③ 路由函数齐备但 main.py 零调用（follow_route 0 次）

⇒ 一句话：**场景系统只完成了"看懂世界"的部分，没有完成"让角色在世界里走动"的部分。**
   用户想要的（看门、切场景）属于后者，属于尚未施工的阶段。
