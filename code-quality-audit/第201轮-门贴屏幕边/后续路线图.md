## 2. ★★★ 升级规则：这些情况必须停下来等我出方案

出现以下任何一条，**立刻停**，把现象和已排除的可能写清楚，等回复再动：

1. **现象定位不到根因**（不知道该改哪个文件）。允许写一份"诊断报告"作为该轮产物，**但不许顺手改代码**。
2. **改法有两条以上都说得通**，且影响用户可见行为。
3. **要动这些"不可回退契约"**：虚拟屏幕矩形取景 / `floor_visible_contains` / `data_store` 唯一入口 / 素材像素 / `320×240` 相机契约。
4. **要动回归判据**（除本轮明确允许更新的那几条）。
5. **方案与本轮遇到的情况对不上**（比如方案说改 A，但发现真凶在 B）。
6. **需要用户拍板的口径**（第 5 节列了三条，没裁定不许猜）。
7. 回归报红，且**不是**你能一眼说清的原因。★ 报红先怀疑判据，再怀疑夹具，最后才怀疑代码。

> 一句话：**宁可停下来问一句，不许"先凑个绿的看看"。**
