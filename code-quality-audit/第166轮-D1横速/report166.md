## 2. D1 是什么，为什么它不是"跳得不准"

```python
# 改前 handle_jump
vx = delta_x / self.jump_duration     # 横向速度由**目标位置**反推
```

病根是**因果反了**，不是精度：

1. **站着不动也能横移** —— 违反 `motion2d` 推论1（`v = 0 ⇒ 位移 = 0`）。
   第164轮把真抛体写进纯函数层时，文档里那句「`vx, vy` 是初速度，一旦起飞就锁定，
   调用方在飞行中只能按 `x += vx*dt` 推进，**不许**再按目标位置插值」，产品侧一直没接上。
2. **这个值不受任何速度上限约束** —— 闸门（`_jump_reach_ok`）会拒"太远"，
   但那只是**拒绝**，一旦放行，`vx` 就是 `dx/T`，比他能跑的任何速度都大也照样给。
   外部入口直接调 `start_jump` 时更明显。

## 3. 用户口径（四问定下来）

1. **落点由物理算**（"全速抛体"）：速度在起跳那刻锁存，`x = x0 + vx0·T` = **结果**。
2. **起跳点/速度都可调**（"全速＋调起飞点＋选速"）：助跑距离本来就是 `L = v_need²/(2a)`
   反算的 ⇒ 冲到起跳点时末速 `sqrt(2aL) == v_need`。这不新增几何，只是把口径说清。
3. **近跳豁免助跑**：未助跑时 `vx` 仍取 `|dx|/T`（闸门已保证它 ≤ `_max_run_px_s()`）
   ⇒ 这一段与改动前**逐值相同**，动作节奏零变化。
4. **阈值内吸附（12px），超出如实掉**：落点仍在目标层可见区域内就就地落，出去了 `start_falling()`。

> ⚠️ 有一条**我给错的选项被自己纠正了**：我原以为"近跳豁免"能省掉后退动作，
> 实际近跳需要的助跑 `L = v²/(2a)` 最短（dx=60 只要 3px，被 `RUNUP_MIN_PX=40` 夹住），
> 而豁免会让 `dx < 走路速×T = 151.5px` 的跳**全部冲过头**（落点恒 151.5）。
> 数据摆出来重问后，用户改成「近跳豁免但**不**按走路动量」（即近跳仍按 `v_need` 给）。

`_lock_jump_velocity` 的两档口径（`check166 B` 段守）：

```
_runup_ready 且 实测>0  ⇒  v_lock = min(实测峰值, RUNUP_SPEED_MAX × run倍率)   # 真跑出来多少就多少
否则                    ⇒  v_lock = |dx| / T                                  # 近跳豁免，逐值不变
vx0 = sign(dx) × v_lock（dx == 0 ⇒ 恒 0）
vy0 = (Δy − 0.5gT²) / T
```

## 7. 本轮判据自己踩的四个坑（**全是我的判据错，不是产品的**）

1. **`_funcdef` 全树找第一个同名函数** ⇒ 抓到的是**别的类的 `__init__`**。
   `RalseiPet.__init__` 的跳跃状态真身其实是 **`init_movement`**（第 1156 行调用它）。
   结果 `A2/A2b` 恒假、`A3` 负控制恒真 —— **一假一真互相掩护**。
2. **`D3` 只扫 `ast.Name`**，而产品里是 `getattr(self, '_lock_jump_velocity')` ——
   **字符串字面量**，不是 `Name` ⇒ 判据恒假。（同族：`D2` 的 `JUMP_SNAP_PX` 是模块级名字，
   不是 `self.` 属性，只扫 `Attribute` 也会恒空。）
3. **`C3` 第一版写成嵌套 lambda**，读不出在测什么 ⇒ 改成直白的两条（行为 + 逐值）。
4. **`recheck166 ⑥` 的"基线是绿的"原来是恒真**：键缺失时 `_ent = {}`，
   `not _ent.get('fail')` 变成 `not None == True` ⇒ 专门掩护上面那条"键不在"的红。
   改成**连"键在不在"一起判**。

另外三条**预期值是我估的、实测不符**（不是产品问题）：`self._jump_vx0` 出现 6 次（我写 8）、
`JUMP_SNAP_PX` 代码使用 2 处（文本 5 处，含注释）、`vx = delta_x / ...` 文本 2 次
（1 条语句 + 1 处注释引用）。**估出来的数就是假判据**，改成逐点核对 + AST 计数。
