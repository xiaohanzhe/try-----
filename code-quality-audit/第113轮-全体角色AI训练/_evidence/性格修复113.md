# 第113轮 · 性格质量修复（用户口径：「尤其性格，也要好好做」）

> 这条线不是"让角色多说几句有个性的话"，是**先把不可用的挑出来**。
> 判据全部可复算，数据在 `_evidence/raw30/`，旧数据在 `_evidence/raw30_old_rule/`。

## 一、体检暴露的两类问题

### 1）语言：10/25 人中文占比不合格

| 角色 | 平均中文占比 | 症状 |
|---|---|---|
| `hy_dalv` | **0.00** | 36/36 轮整段英文 |
| `hy_chujin_ketsukane` | **0.00** | 同上 |
| `hy_clover` | **0.00** | 同上 |
| `hy_guardener` | **0.00** | 同上 |
| `hy_axis` | **0.00** | 同上 |
| `hy_flowey` | **0.00** | 同上 |
| `hy_bowll` | 0.04 | 近乎全英文 |
| `hy_martlet` | 0.08 | 同上 |
| `hy_ed` | 0.41 | 半句英文 |
| `hy_sousborg` | 0.54 | 中英夹杂 |

**根因**：`SPEAK_RULES` 里**一句"用中文"都没有**。这些人设原文里大段引用英文台词
（`"You better watch out!"`、`"Please leave."`），模型顺着台词的语言走。
对中文用户来说这不是"风格差异"，是**这个角色不可用**。

### 2）长度：3 人用「长」冒充「话多」

| 角色 | 均长 | 峰值 | 超 220 字轮次 | 36 轮总耗时 |
|---|---|---|---|---|
| `hy_martlet` | **257** | 400 | 34/36 | **31.3 分钟** |
| `hy_dalv` | **272** | 394 | 27/36 | **25.8 分钟** |
| `hy_bowll` | **262** | 478 | 25/36 | **21.5 分钟** |
| 其余多数角色 | 37~163 | — | 0~3 | 4.3~13.4 分钟 |

**两个副作用**（都很贵）：
- 产品侧 `AI_REPLY_MAX_CHARS = 220` 是硬约束 ⇒ 超长会被判 `TOO_LONG` ⇒ **判退必重采样**
  ⇒ 每轮最多 3 次调用。这就是 21~31 分钟/人的来源（别人 5~13 分钟）。
- "话多"这个性格**根本没演出来** —— 观众看到的是"这个 AI 话说不完"，不是"这个角色絮叨"。

**根因**：`SPEAK_RULES` 里写的是「一次只说 1~3 句」，模型把它理解成
**"1~3 个长句"**。约束的是"句数"，不是"长度"。

## 二、修法：一条全局规则，不是三个逐角色补丁

`ralsei_pet/modules/npc_persona.py` 的 `SPEAK_RULES` 追加：

```
每句话本身也要短，一句话就是一口气的长度。
想表现话多、激动、紧张、絮叨，就用几个短句连发
（同一句话也可以断成两三截来说），不要把一句话写得又长又满，
也不要为了显得有性格而堆长句。
```

**为什么写全局而不是逐个 patch**：
- 语言和长度是**所有 NPC 的共同前提**，逐角色补会漏（以后新加角色又要补一次）；
- `patch` 的语义是"纠正个别毛病"，而这里是"说话方式本身"；
- 实测 3 个作话痨/防御型角色（Martlet / Dalv / Bowll）同时中招，
  说明是**规则缺位**，不是角色个案。

## 三、验证方式（A/B，同角色同提问）

旧规则的记录**先挪进 `_evidence/raw30_old_rule/`** 再重跑，否则 `append_jsonl`
会把两条 36 轮记录追加进同一个文件，新旧混在一起没法对比。

- **A 组**（旧规则）：`raw30_old_rule/{hy_martlet,hy_dalv,hy_bowll,asgore}.jsonl`
- **B 组**（新规则）：重跑同样 36 轮，落回 `raw30/`
- **负对照 `asgore`**：本来就不超长（均长 122、峰值 200、0 超长）。
  它必须**不变差**——如果连它都变短变怪，说明新规则在压所有角色的表达，那就是修过头了。

（B 组数据待填：见本文末尾「实测结果」）

## 四、复跑机制改成数据驱动

`_tools/chain113.py` 原来只按「中文占比 < 0.60」点名复跑 —— **`hy_martlet` 会被漏掉**
（它中文 0.9+，问题在长度）。改成 `needs_rerun()`：

```
中文占比 < 0.60  或  超 220 字的轮次 ≥ 25%
```

并且加了**复检**：复跑完再体检一次。不合格就明说"问题不在说话规则，得看原文"，
**不再整批重跑** —— 没有这一步，"跑过了"会被当成"修好了"。

## 五、一个必须先说清楚的次序

**主训练是 5~13 分钟/人，不是几分钟。** 早期记的「99 秒/人」是**房间四档**的数
（四档合成一段对话 154s → 99s），不是主训练。77 人 × 均值 10.7 分钟 ≈ **13.7 小时**。
排期、判"是不是卡住了"，都要按这个量级。
