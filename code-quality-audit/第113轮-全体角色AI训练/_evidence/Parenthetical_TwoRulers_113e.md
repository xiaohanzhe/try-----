# 括号旁白：两把尺同时失效（第113轮e）

> 触发：第113轮冒烟（`asgore` 48 轮 + `susie` 48 轮）。
> 结论：**指标说「违规 2/48」，实际 48 轮里 45 轮都在写旁白——两处判据同时放行。**

---

它上一轮 36 轮跑出 0 违规（**那正是旧判据漏报的结果**），所以这次没拿到纠正块。

## 2. 真缺陷：两把尺同时失效

模型每一轮都这么写：

```
烦死了。（你皱起眉头看着屏幕那边的人，"你别这么盯着我看。我才没空想东想西的！"）
```

**第一种失效——训练判据太窄**（`common113.py`）：

```python
_PAREN_RE = re.compile(r'[（(][^（()）]{1,30}[)）]')      # 括号内最多 30 字
```

模型写的旁白常 40~80 字 ⇒ **完全不匹配**。48 轮里只报了 2 轮（那 2 轮括号短）。

**第二种失效——产品护栏覆盖不到**（`event_speech.py`）：

| 闸 | 判据 | 为什么放行 |
|---|---|---|
| 甲 `_ACTION_PAREN_RE` | 括号内以**动作/发声动词**开头，且 `{0,16}` | 这里是「**你**皱起眉头」——代词开头、且超长 |
| 乙 `looks_like_narration` | 句首括号 | 括号在句中 |
| 丙 `_NARRATION_INNER` | 只认「心里/语气/神情/眼神…」开头 | 「**你**的…」不在名单 |
| 任意括号对 `_ANY_PAREN_RE` | `{0,40}` 上限 | 长旁白**连进都进不来** |

⇒ 实测 4 条真实输出，产品护栏 **0 条被处理**。真机上用户会逐轮看到旁白。

### 判定方法（可复跑）

```
_tools/ab_gate_vs_guard113e.py   # 同一条输出，训练判据 vs 产品护栏
_tools/ab_head_paren113e.py      # 改前(HEAD) vs 改后 逐条对照
_tools/verify_paren113e.py       # 正/负控制成对
```

## 3. 修了什么

| 文件 | 改动 | 理由 |
|---|---|---|
| `common113.py` | `_PAREN_RE` 上限 `{1,30}` → `{1,200}` | 括号内不允许嵌套，放到 200 不会跨句吞 |
| `event_speech.py` | `_ANY_PAREN_RE` `{0,40}` → `{0,200}` | 同上，让丙闸有机会判 |
| `event_speech.py` | 新增 `_SECOND_PERSON_NARRATION`：`你/您 + 身体部位/神情词` 或 `你…说道/问道/道` | 这是模型最常写的形态 |
| `event_speech.py` | 新增 `_QUOTED_IN_PAREN`：括号内出现引号 | **零误伤**：台词不会在括号里再套引号 |
| `event_speech.py` | `_kill_narration` 的条件改为三者取或 | 挂上去 |

### 改前改后对照（`ab_head_paren113e.py`，HEAD 版函数直接 import 对照）

| 类 | 样本 | HEAD | 现在 | 判定 |
|---|---|---|---|---|
| 正 | 第1/3/4/6 轮（4 条真实输出） | 留 | **删** | ★ 本轮改变 |
| 负 | `（你懂的）`/`（你说的对）`/`（笑）`/`（其实我很害怕）`/`（你叫什么名字）`/`（你想去吗）` | 留 | 留 | 未变 |
| 负 | `（小声）别告诉别人。` | 删 | 删 | **未变——老闸既有行为**，不是本轮引入 |

**改变条数 = 4 = 正控制条数** ⇒ 零副作用。

## 4. 两把尺**刻意不同**（别顺手统一）

| 样本 | 产品护栏 | 训练判据 |
|---|---|---|
| `（你懂的）那种感觉。` | **保留**（正常口语） | **报违规**（任何括号都算） |
| `（其实我很害怕）但我还是要去。` | **保留**（第一人称心里话，既有裁定） | 报违规 |

产品是"删掉特定旁白形态、保留人设的括号表达"；训练要的是"模型压根别写括号"。
口径不同是**设计**，套件里 `C9` 显式断言了这一点。

## 5. 根因（治本还没做）

```
76 份人设文件**全部**含括号，共 1262 处
hy_bowll 40 处 / tenna 27 / hy_guardener 27 / hy_moray 24 / hy_starlo 23 ...
```

⇒ 模型是在**模仿人设的写法**，不是跑飞。产品护栏已经能兜住显示层，
但要让模型自己少写，还得在 `build_system_prompt` 里加**常驻硬规则**
（现在只有"以前违规过"的角色才拿到 `patch`，`asgore` 就是漏网的那个）。
