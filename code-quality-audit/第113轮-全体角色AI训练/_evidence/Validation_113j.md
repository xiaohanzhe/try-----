# 第113轮j · 空间认知：NPC 先得知道自己在哪儿

> 用户口径（2026-10-26 逐字）：
> 「对了，方便的话可以**训练一下他们寻路的能力**（包括**地方偏好**，**特定事件时去的地方**等等）」

---

## 1. 结论先行

**「寻路」不是让模型做路径搜索。**

`npc_roam.step()` 早就是**确定性权重决策**（`npc_intent.action_weights` + 场景特质调权），
模型**完全不参与**寻路 —— 它只负责"说话"（`npc_speak`）。让 7B 去做 A* 既慢又不可靠，
而且会与既有决策层打架。

真正的缺口在 prompt 里：

| | 已有 | 缺 |
|---|---|---|
| 环境 | `trait_hint()` ＝「这地方**什么样**」（人多/安静/昏暗） | — |
| 坐标 | — | 「你**在哪儿**」（城堡镇 / 荒野 / 桌面） |
| 归属 | — | 「你**家**在哪、累了想回哪」 |

模型不知道自己站在城堡镇还是荒野，自然谈不上"想回哪、要往哪去"。
⇒ **本轮给的是坐标事实，不是寻路算法。**

落地第一层：**在哪 / 归属地**。第二层（地方偏好、特定事件去的地方）待做，见 §7。

## 2. 落地清单

| 文件 | 内容 | 行数 |
|---|---|---|
| `ralsei_pet/modules/npc_life.py` | `room_word()` · `place_hint()` · `place_container()` · `PLACE_SEP` / `PLACE_JOIN_ALT` / `PLACE_FILLER` | 789 → **873** |
| `ralsei_pet/src/main.py` | `_scene_label_map()` · `_scene_place_label()` · `_npc_life_blocks()` 的 **⓪ 分片** | 16532 → **16654** |

生产的 prompt 块（真实数据，`ut_toriel` 站在 UT 教室）：

```
【你现在在哪】town church。
【你的归属地】torielclass —— 你平常在那儿待着，累了会想回去。
（这些是位置事实，不是台词 —— 顺着说自己要去哪、想回哪就行，别照着念。）
```

三个设计决定：

1. **⓪ 排在【你周围】之前** —— 位置是坐标事实，"这地方什么样"是在它之上的描述。
   顺序反了，模型先读到"这里很安静"再读到"你在城堡镇"，会把地名当形容气氛的词去发挥。
2. **`home` 走 `npc_placement.home_of()`** —— 与"回家 / 就寝"**同一个出口**
   （登记 home > 回落 scene > None）。不另算一份，避免"它以为家在 A、roam 却送回 B"。
3. **`at_home` 由调用方判好再传** —— 否则 `here == home` 时仍说"你平常在那儿待着，累了会想回去"，
   模型会以为家在别处、回一句"那我该回家了"，**而它就在家**。
