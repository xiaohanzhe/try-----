### 2.3 ★★★ 这个结果不能直接读 —— 探针本身有缺陷

`RULE_BLOCK` 里那条正例是：


这是 **susie 的台词**（第113轮e 的 A 段正控制样本就是从这句来的），却被用在**所有角色**身上。

## 3. 量化：括号里到底包了什么

对 asgore / susie 两个角色的冒烟语料做形态统计（`_evidence/`，工具见 `_tools/`）：

| 角色 | 括号总数 | **含引号**（包着台词） | 纯动作/心理旁白 |
|---|---|---|---|
| asgore | 81 | **0**（0%） | 81 |
| susie | 48 | **47**（98%） | 1 |
| 合计 | **129** | **47（36%）** | 82 |

★★★ 这条数据直接推翻了我原先的假设：我以为「括号 = 纯旁白，删了就干净」。
实际上 **susie 的括号 98% 是「括号里包着要说的话」**：

```
（你皱起眉头看着屏幕那边的人，"你别这么盯着我看。我才没空想东想西的！"）
```

按旧护栏处理 ⇒ **整句（旁白 + 台词）一起被删** ⇒ 用户看到空回复或半截话。
这不是「多了一点旁白」，这是**把角色要说的话吃掉**。

⇒ 所以本轮的核心修复**不是「删得更狠」，而是「先救出台词再删旁白」**。

## 4. 本轮三处改动

### 4.1 `ralsei_pet/modules/event_speech.py` —— 新增「丁闸：救出台词」

```python
_QUOTED_SPAN_RE = re.compile(
    r'[\u201c\u0022\u300c]([^\u201c\u201d\u0022\u300d]{1,300})[\u201d\u0022\u300d]')

def _rescue_quoted(m):
    """括号内有引号 ⇒ 返回引号里的台词；没有引号 ⇒ 原样返回（交给后面几道闸）。"""
    inner = m.group(1) or ''
    spans = [s.strip() for s in _QUOTED_SPAN_RE.findall(inner)]
    spans = [s for s in spans if s]
    if not spans:
        return m.group(0)
    return ''.join(spans)
```

调用顺序是**硬约束**（`_strip_action_parentheticals` 内部）：

```python
_before = text
# 丁闸（第113轮f）：**先救出台词**
t = _ANY_PAREN_RE.sub(_rescue_quoted, text)
# 甲闸：动作旁白
t = _ACTION_PAREN_RE.sub('', t)
# 丙闸：描述性旁白
t = _ANY_PAREN_RE.sub(_kill_narration, t)
```

**为什么救出闸必须排第一**：它做的是「把括号换成括号里的台词」，
若排在删除闸之后，包台词的括号已经被删掉了，救无可救。

**为什么不用「删除」代替「救出」**：susie 那句里，旁白是「你皱起眉头」，
台词是「你别这么盯着我看」——删掉旁白是**对**的，删掉台词是**丢了半句回复**。

### 4.2 判据上限放宽（漏报主因）

| 位置 | 旧 | 新 | 理由 |
|---|---|---|---|
| `common113._PAREN_RE` | `{1,30}` | **`{1,200}`** | 括号内不允许嵌套，最长真实样本远超 30 字 |
| `event_speech._ANY_PAREN_RE` | `{0,40}` | **`{0,200}`** | 同上；`{0,40}` 时 40 字以上的括号整体漏过 |

> 注意：这是**放宽上限**不是放宽语义 —— 仍然「出现任何括号就算违规」。

### 4.3 `train30.py` —— 偏好问法与判据

**问法**（`PREF_TEMPLATES[0]`）原来只能答二选一，改成要具体细节：

```python
'我注意到你好像挺喜欢「%s」的。喜欢它哪一点？说个具体的——你平常是怎么弄的？',
```

**判据**原来「逐字命中主题词」⇒ 假红。asgore 答「照顾那些花」「花店的香味」「和 Toriel 在花园」
却因为**没写「园艺」二字**被判 0。改为：

```python
_PREF_GENERIC = ('在线', '游戏', '东西', '地方', '时候', '什么', '事情', '感觉',
                 '工作', '一个', '这个', '那个', '自己', '别人', '喜欢', '爱好')
```

`pref_stems(topics)` 取 2 字切片并剔掉泛词，命中判定放宽为「**原词 或 去泛化词干**」。
实测 `在线滑板游戏 → ['在线滑板游戏','线滑','滑板','板游']`（`游戏`/`在线` 被剔掉，不再误判）。
