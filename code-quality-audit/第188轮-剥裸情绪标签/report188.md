## 3. 为什么不能"往动词表里加词"（两个坑都踩过）

### 3.1 甲闸抓不到它们，是**故意的**

`_ACTION_VERBS` 上方第 589 行有一句注释明写：

> 裸 `笑` 会命中 `（笑不出来）`

锁 `A22g` 实测过这条：`（笑不出来）` 是**真情绪表达**，删了就丢语义。
所以 `笑` **没有**进 `_ACTION_VERBS`。如果我图省事把 `笑` 加进去，
`A22g` 当场变红，而且用户会看到"我笑不出来"变成"我"。

顺带一个反直觉事实：`_ACTION_VERBS` 里**已经有** `点头|摇头|皱眉|沉默|停顿|叹|歪|低头|眨眼`
—— 也就是说产品侧本来就在删 kris 的 `（点头）`，**不存在"某个人物豁免"**。

### 3.2 等值词表会无穷增生

真正要覆盖的形态是 `（笑）` `（微笑）` `（苦笑）` `（思考片刻）` `（微微一笑）`
`（笑眯眯地）` `（犹豫了一下）` `（尴尬地笑）` `（轻咳）`……

这是一个**开放集**：修饰语 × 情绪词 × 后缀 = 组合爆炸。
"动词表要穷举"是本项目踩过的老坑（第161轮、第187轮各栽一次）。
加词只能追上今天这 419 条，明天训练产出换个说法又是新的洞。

## 4. 修法：整段**形态**匹配，不是词表

```python
_BARE_MOD  = 微微|轻轻|稍微|稍稍|淡淡|浅浅|勉强|尴尬地|自嘲地|无奈地|……|轻|微
_BARE_MOOD = 微笑|苦笑|冷笑|大笑|失笑|笑眯眯|笑|叹气|轻叹|长叹|叹|沉默|停顿|
             点头|摇头|皱眉|思考|犹豫|脸红|尴尬|开心|难过|紧张|惊讶|无奈|咳
_BARE_SUF  = 了一下|了下|着|地|了|片刻|一阵|一下

_BARE_LABEL_RE = ^\s*(修饰语)?\s*(一)?\s*(情绪词)\s*(后缀)?\s*$
```

判据是**整段**必须符合这个形状才删。于是：

| 输入 | 结果 | 原因 |
|---|---|---|
| `（笑）` `（微笑）` `（苦笑）` `（思考片刻）` `（微微一笑）` | **删** | 整段 = 情绪词（可带修饰/后缀） |
| `（笑不出来）` | **保留** | `不出来` 不在后缀集 ⇒ 天然不命中（`A22g` 继续绿） |
| `（微笑切面条）` | 保留 | 情绪词后面跟了宾语 |
| `（红色眼睛微微闪烁）` | 保留 | 角色特征，属 C 族 |
| `（其实我有点怕）` | 保留 | 第一人称心里话 |

### 4.1 一个实测补出来的坑

第一版正则漏了 `一` 这个量词位：

```
（微微一笑）  → 不匹配（正控制当场变红）
```

`一` 既不是修饰语也不是后缀。补 `(?:一)?` 后过。
**只允许一个 `一`** —— `（一直笑着）` 是真台词，不该删。

### 4.2 闸序不可换

四道闸的现行顺序：

```
丁  _rescue_quoted     救引号台词   ← 必须最先
甲  _ACTION_PAREN_RE   动作动词开头
丙  _kill_narration    叙述
戊  _kill_bare_label   裸标签       ← 本轮新增，排在丁之后
```

戊闸如果跑到丁闸前面，`（笑"我真的没事"）` 会**连台词一起没**。
判据 `C3`（行为）与 `D3`（AST 行号顺序）成对钉这一条。
`D2` 另钉"`_ANY_PAREN_RE.sub` 恰好 3 处"，防止下次有人手滑加第五道没登记。

`(?!)` 必须让残留数**回到 312**，否则"改前基线"本身不成立（本轮实测 rc=0，回到 312）。

### 5.2 改后仍残留 243 轮，按族拆开

| 族 | 轮数（一轮可含多族） | 典型形态 |
|---|---|---|
| **B 第二人称叙述** | 92 | `（你在围裙口袋里找创可贴）` `（你轻声说）` |
| **C 角色自身特征** | 49 | `（红色眼睛微微闪烁）` `（活塞手臂微微颤抖）` |
| **D 台词错位** | 52 | `（NYEH HEH HEH!）` `（SANS! STOP BEING LAZY!）` |
| 其他 | 79 | 见 §5.3，**混杂** |

### 5.3 ★★★ 「其他」79 轮是混杂的 —— 这条是本轮最重要的发现

把"其他"去重后是 87 种 / 92 处，按长度和句内标点再切一刀：

**A. 短（≤10 字）且无句内标点：63 种 / 68 处 —— 仍是混杂**

```
该删的近似裸标签                     绝不能删的第一人称插话
─────────────────────────────      ─────────────────────────────
撇了下嘴 / 嘿嘿笑了下 / 嘿嘿笑了一声     我还相信你
露出勉强的笑容 / 露出一个微弱的笑容      希望你能理解
皱了下眉头 / 皱了眉想了想 / 想了想      虽然他说的其实是假话
深呼吸 / 起身伸懒腰 / 轻拍胸口          虽然还是想偷点东西
眨眨眼 / 得意地笑 / 自嘲地笑了笑       或至少大部分
```

**`（我还相信你）` 只有 5 个字、没有任何标点，结构上和 `（想了想）` 一模一样。**

这就是形态匹配的**边界**：再往外扩（比如"短且无标点就删"），
第一个被吃掉的就是这种真人台词。

**B. 长或带句内标点：24 种 / 24 处 —— 几乎全是内容**

```
（直接一点嘛。看看他带了啥好东西来给我。）
（我知道，这并不是真正在意的事情，但我要表现出我很认真）
（内心独白：但别忘了我的策略哦，总要站在赢家那边才行！）
```

**结论：戊闸的边界画对了 —— 它停在"整段就是一个情绪词"这个可判定的形状上。**
再往里扩不是加词的问题，是**换机制**的问题（需要判断"这句是不是台词"，
而不是"这个括号像不像标签"），必须单独拍口径。

## 6. 本轮**明确不做**的三族（如实留档）

| 族 | 为什么不做 |
|---|---|
| **B 第二人称叙述**（92 轮） | `（你在围裙口袋里找创可贴）` 是**替玩家叙述动作**。删了玩家会失去"我在做什么"的线索；提出来变成正文又变成桌宠在指挥玩家。要先定"桌宠能不能替玩家叙述"。 |
| **C 角色自身特征**（49 轮） | `（红色眼睛微微闪烁）` 是**角色外貌描写**，不是动作。删了丢设定感，留着又出戏。真正该做的是**在提示词里禁掉**，不是护栏删。已实证提示词层对此无效（第187轮），所以这一族的正确去处是"接受它存在"或"改人设写法"。 |
| **D 台词错位**（52 轮） | `（NYEH HEH HEH!）` 是模型把台词写进了括号。删了**丢内容**，提出来等于**替模型改写台词**（护栏不该做创作）。需要单独决定"括号里的台词要不要搬到正文"。 |

三族合计占残留的大头。**本轮只把"最没争议的一族"（裸标签）吃掉**，
剩下 243 轮的每一族都要用户拍一句口径，不能我自己推。
