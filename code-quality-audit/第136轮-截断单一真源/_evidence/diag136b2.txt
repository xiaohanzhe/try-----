① `fit_sentences` 的差异**只**出现在哪些上限上
  max=40  差异   0 条  
  max=24  差异   0 条  
  max=20  差异   0 条  
  max=16  差异   0 条  
  max=12  差异  30 条  例：'aaaaaaaaaa！！！' on='aaaaaaaaaa' off='aaaaaaaaaa！！'
  max=8   差异  30 条  例：'aaaaaa！！！' on='aaaaaa' off='aaaaaa！！'
  max=6   差异  84 条  例：'aaaa！！！' on='aaaa' off='aaaa！！'
  max=5   差异   0 条  
  max=3   差异   0 条  

⇒ 默认 40 与事件链 24 上**都是 0 条**；差异只在 max < 本次语料里"前缀+标点"的长度时才出现。
  形状是：run-final 放不下 ⇒ eat 把这个切点整个从 ok 里删掉 ⇒ 退回更早的切点。
  默认上限下这个形状要求"连续标点正好跨在上限位置"，本语料 0 命中。
