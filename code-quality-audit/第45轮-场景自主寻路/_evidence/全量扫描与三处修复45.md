## 0. 这一轮是怎么被"逼"出来的

起点是**鉴别力体检**（5 个"故意破坏"用例）里有 2 条**完全不报红**：

```
[FAIL] 破坏4 A* 找不到路时返回穿墙直线 -> 完全没有报红 ⇒ 恒真判据
[FAIL] 破坏5 平滑不再回退 -> 完全没有报红 ⇒ 恒真判据
```

逐层查证后得到**两类不同结论**：

| 现象 | 真因 | 处置 |
|---|---|---|
| 破坏4 不报红 | **破坏手法写错**：`cells = [s, g]` 插在 `out['reason']=...` 之前，被紧邻的 `return out` 吞掉，破坏根本没生效 | 改成整段替换（去掉 reason/return） |
| 破坏5 不报红 | **夹具没鉴别力**：E10/E11 用的 `krishallway` 路线因 `SAFETY_PAD=3` 离墙够远，裸 chaikin 恰好不穿墙 | 新增 E13（`pad=0` 贴边折线夹具），裸 chaikin 必穿 |

> ★ 教训：**"判据不报红"有两种可能 —— 判据恒真 / 破坏手法没生效。**
> 必须先用探针区分，再决定改判据还是改手法。这次两种都遇到了。

## 1. ★★ 真正的收获：五章全量扫描暴露 3 个真 bug

在做破坏2 的量化时（"`SAFETY_PAD=0` 到底还有没有劣化？"），
顺手把扫描范围扩到**五章全部有障碍的房间**，结果发现
**未修改的代码在真实数据上也有 17/2376 处相邻航点连线穿模**：

| 章 | 样本 | 点穿模 | **段穿模** |
|---|---|---|---|
| ch1 | 750 | 0 | **4** |
| ch2 | 696 | 0 | **2** |
| ch3 | 324 | 0 | **2** |
| ch4 | 300 | 0 | **2** |
| ch5 | 306 | 0 | **8** |
| 合计 | 2376 | 0 | **17** |

> ★★★ 这正是"**行为判据必须用真实量级输入**"的落地：
> D/E 段只用 `krishallway` / `town_north` 应付得过去，全量一跑就露馅。

### bug ① `simplify_collinear` 按"共线性"删点会切角

旧注释写着"只删真的在直线上的点，不改变路径形状 ⇒ 不影响可走性"。
**这句是错的。** A* 的格心折线在**绕障碍凸角**时呈**锯齿状**，
其中继点恰恰近似共线；删掉后 `A→C` 直连就**切进了障碍**。

```
ch1 room_flowershop_1f  末段 (95,85) -> (36.58,134.67)
  直插 (20,134,105.26,25.26) 这个柜台
```

**修复**：`simplify_collinear(points, align, obstacles=None, ...)`
—— 传了 `obstacles` 就变成"**保行走简化**"：删点会让新段穿墙的，就不删。
不传时保持旧的纯几何行为（E6/E7 判据不受影响）。

### bug ② 首尾用"替换"而非"插入"，抹掉已验证的短段

旧代码：

```python
pts[0] = (sx, sy)      # 「替换」s 格心
pts[-1] = (gx, gy)     # 「替换」g 格心
```

可 `_nearest_free_visible()` 刚验证过的正是
「`(sx,sy)` → **s 格心**」这条短段。替换把它抹掉后，
首段变成「`(sx,sy)` → **第二个**格心」，**跨过了障碍**。

```
ch1 room_torielclass
  s 格心 (55,45) 与起点直连 clean=True      ← 已验证合法
  替换后首段 (140.6,45.7) -> (55,35)  ❌ 穿 (84,48,142,20) 那张桌子
```

**修复**：改为**插入**

```python
pts = [(sx, sy)] + pts + [(gx, gy)]
```

### bug ③ `_nearest_free` 只按欧氏距离找格，不管连线是否被挡住

旧版螺旋找"最近可走格"，**完全不看** `(px,py)` 与那个格之间有没有障碍。

```
ch1 room_torielclass：起点 (140.6,45.7) 本身可走，
  但"最近可走格"螺旋找到 (115,5)，二者之间横着 (84,48,142,20) 那条桌子
  ⇒ 路径首段直接穿桌
```

**修复**：新增 `_nearest_free_visible()` ——
判据是「**格可走 且 与真实起终点直连不穿墙**」，两项缺一不可。
找不到 ⇒ `None` ⇒ 如实报"走不到"（不硬凑）。

## 2. 修复后的复检

### 2.1 五章全量扫描（seed=20260925，逐房间 3 组起终点 × 2 平滑模式）

| 指标 | 修复前 | 修复后 |
|---|---|---|
| 点穿模 | 0 | **0** |
| **段穿模** | **17 / 2376** | **0 / 2376** |
| pad=0 段穿模 | 14 / 2376 | **0 / 2376** |

### 2.2 回归锁 `verify_walk45.py`：**PASS=90 FAIL=0**（8.6s）

新增段落：

- **D7b**：把 D7 夹具前提钉住（"切的是连通性，不是起点不可站"）
- **E13a~f**：贴边折线夹具（专治"平滑不回退"），含**正控制 E13c**
  「裸 chaikin 在此夹具上**必须**穿墙」——证明夹具真有鉴别力
- **G1~G3**：五章全量扫描（覆盖 408 间房 / 714 可规划样本 / 78 如实报走不到）
- **G4**：已知脆弱房间深度判据（5 间房 × 2 模式 = 10 次规划）

> ★ 为什么 G 段之外还要 G4：把"保行走简化"去掉后，五章仍有 **2 段**穿模，
> 但 G 段"每间房 1 组"的 714 样本**恰好没命中** ⇒ 判据漏报。
> G4 把这些"曾出过事"的房间钉死，保证同类退化**必然**被抓。

### 2.3 鉴别力体检 `disc_walk45.py`：**6/6 PASS**

| 破坏 | 命中判据 |
|---|---|
| 1 主 bbox 高度改 38 | C5 / C6b |
| 2 首尾由"插入"改回"替换" | G3 |
| 3 `blocks_at` 恒返回 False | C4a / C5b |
| 4 A* 返回穿墙直线 | D7 / D8 |
| 5 平滑不再回退 | E13d / E13e |
| 6 简化不再校验可走性 | G4 |

> ★ 原「破坏2 `SAFETY_PAD=0`」**已撤掉** —— 原因不是判据恒真，
> 而是**破坏手法已失效**：三处修完后 `SAFETY_PAD` 不再是防穿模的必要防线
> （实测 pad=3 与 pad=0 的穿模数都是 0）。它现在的唯一作用是"让走位离墙远一点"，
> 没有判据能守住。⇒ 换成两个对应本轮真 bug 的破坏。

## 3. 遗留 / 未决

1. **`_nearest_free`（旧版）保留未删** —— 语义上是 `_nearest_free_visible` 的子集，
   但为了让"旧行为"可对照，暂留。**待定**：是否删除（会动公开函数面，需拍板）。
2. **`SAFETY_PAD` 的角色重定义** —— 从"防穿模"变成"走位观感"。
   取值 3 是否合适（`krishallway` 最窄通路 20px，主角 19px）**待观感实测**。
3. **78 次"走不到"的合理性未逐一核** —— 其中应含第 42 轮记录的
   ch4 `torhouse` / ch5 `krisroom` 门实例缺口导致的不可达。**待补采**。
