# Ralsei 桌宠 · 逐步操作指南（给模拟用户）

> 配套文件：`功能说明书-给模拟用户.md`（讲"有什么功能"）；本文件讲"**手怎么动**"。
> 分工：**你操作，我录屏 + 逐帧分析**。你只要按步骤做，并把"看到什么"如实说一句。

---

# 第 0 步 · 开机前检查（约 1 分钟，漏了后面全是白测）

**0-1 确认没有旧实例**
- 按 `Ctrl+Shift+Esc` 开任务管理器 → 找 `python.exe` → 如果有多个，全部结束。
- 原因：它用命名互斥量做单实例锁，**旧实例没死干净时，新实例会直接静默退出**，你会以为"它坏了"。

**0-2 确认模型服务在跑**
- 开始菜单搜 `Ollama` → 打开（**要托盘里有它的图标**，不是命令行窗口闪一下就没）。
- 验证：浏览器打开 `http://127.0.0.1:11434/api/tags` → 应该看到一串 JSON（里面有 `ralsei:v4`）。
- 打不开 ⇒ **后面所有对话都会变成"背台词"**。这一点必须第一时间报给我。

**0-3 启动桌宠**
- 打开命令行：`cd` 到 `ralsei_pet\src`，执行 `python main.py`。
- **预期**：会出现一个黑色命令行窗口持续刷日志（`NPC xxx 自己挪到了 …`）。
- **实测耗时：约 10~40 秒**才初始化完。这期间屏幕上**什么都看不到**，属于正常。

**0-4 露出桌面**
- 按 **`Win + D`**（回桌面，把所有窗口最小化）。
- ★★ **这一步不能省**：桌宠在桌面场景下**不置顶**，任何窗口都会把它盖住。

---

# 第 1 步 · 先确认"它到底在不在"

| 你看到 | 说明 | 怎么办 |
|---|---|---|
| 屏幕**下方中央**有一个黑底白框、左侧有「RALSEI」小头像 | ✅ 活着，最正常 | 进第 2 步 |
| 什么都没有 | 可能还在初始化，或窗口被盖住 | 等 30 秒 → 再按一次 `Win+D` → 还不行就报给我 |
| 只有一个很淡、几乎看不见的影子 | 那是"幽灵"（启动时 alpha≈0.10，故意的） | 正常，不用管 |

---

# 第 2 步 · 看大小与场景（这是本轮重点）

**2-1 量大小**
- 看 Ralsei **本体立绘**（不是对话框）占屏幕多高。参照物：任务栏高度、桌面图标的行距。
- 口述给我一句："大概占屏幕高的 1/4 / 1/5 / 比任务栏高一点点"。

**2-2 看场景**
- 场景应该是一块**四周带黑边的 4:3 画面**，里面是原作的房间。
- 报三件事：**有没有** / **占屏幕多大** / **黑边宽不宽**。

**2-3 看四扇门**
- 应该有 4 扇门：**A 三角符文 / B Niko 家 / C Undertale / D Deltarune**。
- 逐个报：**在哪个方向**（上/下/左/右）、**是不是紧贴屏幕边框**、**有没有半透明**（UT 和三角符文那两扇靠近才显形）。

> ★ 我实测的现状（可作为对照）：**这三样（本体立绘 / 场景 / 门）在屏幕上都看不到**，只有对话框和菜单。所以你如果也看不到，不是你的问题，是缺陷。

---

# 第 3 步 · 让它说话（判断 AI 有没有参与）

**3-1 单击它**
- 鼠标左键**单击** Ralsei 身上（不是对话框）→ 预期出现一句台词。

**3-2 用输入框主动说一句**
- 点对话框下方那个浅色输入条（上面写着「说点什么」）；
- 输入一句中文，例如：`我下午三点去买了个面包`；
- 按 `Enter` 或点右边 **SEND**。

**3-3 观察翻页**
- 原作是"一句话一个框"。触发下一页有三种方式，**逐个试**：
  1. 再**单击**一次；
  2. 什么都不点，**静置 2 秒**；
  3. 点一下输入框后按**空回车**。
- 报：**有没有翻页**、**会不会跳页**（一次跳好几条）。

**3-4 核对"是不是 AI 说的"**
- 说一句**它不可能预先写好的话**，比如：`我刚才查了一下，今天股市跌了 3 个点，你怎么看`。
- 如果它回得像模板、或总在说桌面上的文件名 ⇒ **不是 AI，是内置台词**，立刻报我（我会同步查日志）。

**3-5 试试跳过打字**
- 它正在逐字打字时，按 **`X`** → 应该立刻显示整句。

---

# 第 4 步 · 菜单

**4-1 打开**
- 按 **`Ctrl + Alt + S`**（全局热键，**不用先点中它**）。
- 预期：右下角出现「菜单 / >道具」，底部提示「↑↓ 选择　Enter 进入　Esc 关闭」。

**4-2 逐项点**
- 用 **`↑` `↓`** 移动、**`Enter`** 进入、**`Esc`** 返回。
- 报：**一共几项**（我实测只有「道具」一项）、每一项进去**有没有内容**、**能不能退出来**。

**4-3 第二个热键**
- 按 **`Ctrl + Alt + E`** → 报有没有反应（我没确认它干什么）。

# 第 5 步 · 互动（这几条最像"能玩"的部分）

| 步骤 | 动作 | 预期 | 要报什么 |
|---|---|---|---|
| 5-1 | 鼠标**拖动**屏幕上那颗**红色小方块（SOUL 灵魂）** | 灵魂跟着走；画面跟着切 | 能不能拖动 / 拖了画面变不变 |
| 5-2 | 对着某个 NPC 按 **`Z`** | 请求**附身**，会先问同不同意 | 有没有弹征求同意 / 同意后操控权有没有切过去 |
| 5-3 | 按 **`G`** | 请求某个角色**带路**，走原作路线 | 有没有走 / 是走过去还是瞬移 |
| 5-4 | 点对话框的 **SEND** 旁边区域 / 右键宠物 | 面板、喂食、玩耍之类 | 弹了什么 / 有哪些按钮 / 哪些点了没反应 |

---

# 第 6 步 · 记忆（这条要等一会儿）

1. 对它说：`我下午三点去楼下买了 3 个面包`；
2. **等 5 分钟以上**（做别的测试）；
3. 问它：`我下午干嘛去了？`
4. 再问一次：`我买了几个？`（同一个问题问两遍，看会不会**每次说法不一样**——这是"允许记错"的设计，但**重要的事不该错**）。

---

# 第 7 步 · 明确**不要测**的东西

- ❌ **别让它打开 / 打开文件夹 / 双击桌面文件**：**2026-11-19 起「开文件」功能已废除**。如果它自己主动去开文件、或谈论桌面上的某个文件（例：`xxx绩效考核结果 v1.xlsx`），**立刻记一条缺陷报我**。

---

# 第 8 步 · 收尾

- 结束前告诉我一声，我把进程清干净（命名互斥量残留会让下次启动直接失败）。

# 出问题时怎么报（三句话就够）

1. **我做了什么**（例如：按了 Ctrl+Alt+S）
2. **我等了多久**
3. **屏幕上出现了什么 / 完全没反应**（如果出来了但不对，说哪里不对）

> 不要替我解释原因，也不要猜"可能是我按错了" —— 你如实说现象，根因我来查。
