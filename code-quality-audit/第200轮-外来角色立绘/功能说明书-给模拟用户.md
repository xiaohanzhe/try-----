# Ralsei 桌宠 · 功能说明书（给"模拟用户"用）

> 版本：第200轮（2026-11-19）
> 用途：交给另一个 AI 当"操作者"逐项试用；**录屏与分析由我负责**。
> 口径：本文件只写**代码里确实存在的**能力，以及**我实测到的**现状；拿不准的一律标「待验证」，不猜。

---

## 0. 环境前提（不满足则很多功能看起来"坏了"，其实是没接通）

| 项 | 要求 | 怎么自查 |
|---|---|---|
| 系统 | **仅 Windows**。产品依赖 `pywin32` / `win32gui` / `ctypes.windll` / `CreateMutex` / `RegisterHotKey`，**跑不了 macOS** | `requirements.txt` 含 `pywin32` |
| 本地模型 | **Ollama 必须常驻**（`ollama serve`），默认 `http://localhost:11434` | 浏览器开 `http://127.0.0.1:11434/api/tags` 有 JSON |
| 模型 | `ralsei:v4`（4.7 GB） | `ollama list` |
| 记忆库 | `D:\RalseiMemory\`（**不是** E 盘；E 盘那份曾被污染已废弃） | 起一次后目录里应有 `memory.json` / `npc_memory\` |
| 启动 | `cd ralsei_pet\src && python main.py` | 单实例锁 `Global\RalseiPetMutex`：**重复启动会直接退出**，先确认没有残留进程 |

⚠️ **两条最容易误判的观感前提**

1. **桌宠在桌面场景下"不置顶"**。任何普通窗口（浏览器、编辑器）都会把它盖住 ⇒ **看不到它不一定是它没起来**，先按 `Win+D` 回到桌面再看。
2. **它是透明分层窗口**，只有精灵像素不透明。截图/录屏能看到，但**模拟点击透明区会穿透**到下层窗口。

## 1. 怎么操作（按键与手势总表）

| 操作 | 触发 | 预期看到 |
|---|---|---|
| 打开场内菜单 | **`Ctrl+Alt+S`**（全局热键，不必先点中宠物） | 原作风格菜单（**设置页已摘掉**） |
| 第二个全局热键 | `Ctrl+Alt+E` | 待验证（注册了，具体行为未确认） |
| 附身 | **`Z` 键** | 操控权从"红色灵魂"切到某个角色；会先弹**征求同意**的对话 |
| NPC 交互 | **`Z` 键**（对着 NPC） | 等价原作"射线检测→触发交互" |
| 带路 | **`G` 键** | 请求某个角色**带着灵魂走**（走原作路线，不瞬移） |
| 跳过打字 | **`X` 键** | 仅"正在打字 且 输入框未聚焦"时生效 |
| 拖拽灵魂 | 鼠标拖红色 SOUL | 灵魂可拖到场景各处；**拖动它才会切换显示**（"灵魂视角"是唯一驱动） |
| 单击宠物 | 鼠标左键 | 起话（走翻页队列，一框一条） |
| 对话翻页 | 再单击 / 空回车 / 静置 2 秒（`PAGE_DWELL_MS=2000`） | 下一条 |
| 喂食 / 玩耍 / 清洁等 | 面板按钮（`Ctrl+Alt+S` 菜单或右键） | 能量/饥饿/情绪数值变化 |

> 按键细节若要更准，以运行时为准；上表来自代码里的绑定与注释。

## 2. 功能清单（按"能不能看到效果"分组）

### 2.1 本体与显示

| 功能 | 说明 | 现状 |
|---|---|---|
| 桌宠本体 | 一个透明无边框窗口，Ralsei 立绘 + 动画 | 可用 |
| 走路/待机/睡眠动画 | `animations.json` 115 组；睡眠只允许 `down` 方向拼 `_sleep` | 可用 |
| 表情 | `assets/faces/` 190 张图 / 29 个 id，**零像素改**（按原作原样） | 可用 |
| 缩放 | `camera.scale × pet_scale`；场景与人物**同倍率** | ★ 第200轮已由 `SCENE_FIT_FRACTION` 0.5 → **1/3**（= 原大小的 2/3），场景 1066×800 → 711×533，`scale` 3.331 → **2.222**。**待视觉复核** |
| 幽灵 | 启动时**几乎透明**（alpha≈0.10，"刚好看得见的边缘"），靠近才渐显 | 可用（容易被误判成"没启动"） |

### 2.2 场景系统（"把原作的世界搬到桌面"）

| 功能 | 说明 | 现状 |
|---|---|---|
| 场景全屏化 | 画布 = 整屏固定；画面 = 4:3 内接矩形 × 比例，四周填黑 | 可用 |
| 相机 | 人物走到中间后一直居中，背景相对运动（**是相机平移，不是视差**） | 可用 |
| 桌面 4 门 | A 三角符文 / B Niko家 / C UT / D Deltarune；契约要求**挨着屏幕边框** | ⚠️ **用户实测"不在屏幕边缘"**，正在查（与"场景只占屏幕 1/3"直接冲突，需定口径） |
| 门渐显 | 只对桌面 UT 与三角符文两扇：靠近才从虚到实 | 可用 |
| 换房/相机跟随 | 门 = `Data.Rooms` 下标偏移；无门 = 不可达（不瞬移） | 可用 |
| 可读物 | 原作书/牌等可读文本：164 个场景 / 335 条 | 可用 |
| 扭蛋球 | 光世界容器，滚动/缩放由 `fit_scale` 反推 | 可用 |

### 2.4 对话（★ 本次重点）

| 功能 | 说明 | 现状 |
|---|---|---|
| AI 对话 | 走本地 Ollama `/v1/chat/completions` | ⚠️ **需 Ollama 常驻**；第200轮实测：服务没起时 **10 次请求全失败**，每句重试 4 次 × 5 秒 = 20 秒 |
| 一框一条 | 原作"一句话一个框"；旁白与台词各占一页；**绝不跳页** | 可用 |
| 内在活动 | `（想一想）` 类**删掉不说**，只留停顿；只存关键词（时间/地点/人物/干啥） | 可用 |
| 外在表现 | 括号里的动作 → 删掉 + 说旁白 + 演动画 | 可用 |
| 记忆 | 四要素；**地点是唯一召回锚点**；允许记错（约三成说成"好像说过"） | 可用 |
| NPC 一人一库 | `D:\RalseiMemory\npc_mem\<id>\` 物理分开，防串味 | 可用 |
| 内置台词（预制） | 仍有 **3 处调用点**传 `pool=[...]`（= AI 失败时说写死的台词）；另 26 处已改成"宁可沉默" | ❌ **用户要求全删**，待改 |

> ★ 判断"AI 有没有参与"的可靠方法：**看日志**。有 `本地 AI ... 请求失败` 就是在走内置台词/沉默，不是在跟模型说话。

## 3. 建议的试用路线（按顺序走，方便我对应录屏分析）

1. **能不能看见**：`Win+D` 回桌面 → 有没有 Ralsei？（注意幽灵几乎透明）
2. **大小**：他现在占屏幕多少？和桌面图标比、和任务栏比。
3. **场景**：四周有没有黑边？画面占屏幕多大？
4. **四扇门**：在哪？是不是贴着**屏幕**边框？
5. **说话**：单击他 → 说什么？是 AI 现编的，还是背台词？（对照日志）
6. **菜单**：`Ctrl+Alt+S` → 菜单里有什么，哪些能点，点了有没有反应。
7. **交互**：`Z`（附身/NPC 交互）、`G`（带路）、拖红色灵魂。
8. **记忆**：跟他说一件事（例："我下午三点去买了个面包"）→ 隔一会儿问"我下午干嘛了"。
9. **NPC**：等 30 秒看有没有别的角色在桌面上走动。
10. **异常**：哪些按钮点了**没反应**、哪些话说得**不像他**。
