## 1. 结论先行

- 第131轮的 42 条真机回复里，**3 条**属于"元话语泄漏"——回复不谈事，改为谈论"我该怎么说话"。
  三种形态：

  | # | 形态 | 原文 | 出自人设哪一段 |
  |---|---|---|---|
  | 1 | 规则改写成第一人称自述 | 「你说的是坏消息的时候**我不该用亮起来的开头**，先就着那件具体的事问一句。」 | 「语气示范」第 147~148 行（原文是"一、…不许用亮起来的开头"） |

  | 3 | 括注里自评合规 | 「…（**这里说的是你自己的事，而不是直接给出建议**）」 | 「不要主动给建议…先陪着他」那几条 |

- ★★★ **本轮最重要的一条是负结论**：**用"回复与 system 的字面重合度"判不出来。**
  先写的那版扫描（`scan132_leak.py`）算了最长公共子串与 6-gram 重叠，
  结果 **重合度最高的两条是正常好答案**（`lcs_flat` = 17 和 13），真正的泄漏只有 **10**。
  原因很朴素：人设本身就在讲"城堡/喷泉/角色/Deltarune"，好回复当然用同一批词。
  ⇒ 重合度会**误伤说正事**，抓不住念规则。这条弯路留在报告里，是因为它很可能被下一个人再走一遍。

- 落地的闸：`event_speech.looks_like_meta_leak()`，按**元语言的结构特征**判，
  接进 `_clean_ai_reply` 的第 0c 道（与出戏、客服腔**并列在同一个 if**，命中即 `return None`）。

## 2. 为什么不是"改人设"

「语气示范」那段是编号规则（一、二、三…），确实是"最像指令"的一段，而模型念的就是它。
理论上把编号改成口语能减少诱导，**但那会牵动一条长链**：

- 人设变 ⇒ `persona_sha256` 全 stale ⇒ 96 张训练卡重建 ⇒ `voice_markers` 这类派生字段被冲掉
  （第130轮刚踩过：`kris` 的 5 条变 7 条）；
- `check115` 的四个锚句、`check128` 的 B 段体积/文案断言、`check113 A4` 全要跟着动。

而**护栏是"最后一道兜底"**，改动半径只有一处调用点。所以本轮先兜底；
改人设留成选项（写进 §6 遗留），等真机复测证明"兜底之后仍频繁泄漏"再动。

## 3. 闸门设计：为什么这 5 条规则，为什么是这个形状

```python
_META_LEAK_RES = (
    r'我不该.{0,12}(开头|语气|问一句|留个)',        # ① 我不该 + 说话方式
    r'我(该|应该|本该)先就着',                       # ① 变体：把"不许"背成"我该"
    r'问一句[：:]',                                  # ② 引用模板（带冒号）
    r'留个[「"“]',                                   # ② 引用模板（带引号）
    r'[（(]\s*(这里说|这是说|以上是|注[：:])',        # ③ 括注式自评
)
```

三条设计纪律：

1. **每条都要"两件事同时出现"或"强格式"**。裸词一律不写：
   - 「我不该」单独出现会误伤「我昨天不该说那些话的，对不起」⇒ 必须跟"开头/语气/问一句/留个"；
   - 「问一句」不带冒号会误伤「你问我一句，我就答一句」；
   - 「留个」不带引号会误伤「留个位置给你」；
   - 「（这里」会误伤「（这里有点暗，我看不太清。）」⇒ 必须"这里说/这是说/以上是/注："。
2. **不写"意思"这类松散词**：它会把「我不是这个意思」判成泄漏。
3. **不碰"而不是 + 建议"这种语义判断**：单看它，「不是给你讲道理，而是…」是正常台词。

- 全量数据见提交信息（`check132` 一行为 `0 27 0 IDENTICAL`）。

**遗留**

1. **误伤率只在"我们自己的语料"上量过**（342 条）。真实用户聊天的分布不同，
   尤其"我不该…"这种自责句在小模型里很常见。**上线后要盯 `_log.debug` 里这条闸的触发率**，
   如果发现误伤，第一件事是收窄 ① 而不是整条撤掉。
2. **流式中途看不出来**：泄漏往往出现在句子后段，流式层已经在打字，
   所以这道闸只在**收尾**判（与出站一致）。要不要在流式里做"疑似元话语就暂停"，
   复杂度高、收益不明，本轮不做。
3. **没有改人设**（§2）。如果兜底之后仍频繁泄漏，下一步是把「语气示范」的编号规则
   改写成口语式规则 —— 但那要连带重建训练卡，属于一整轮的工作量。
4. **没有真机复测闸门本身**：本轮只证明"它能把已知的 3 条拦住、不误伤 339 条"，
   没发新请求看"被拦之后重采样出来的那句好不好"。要测就再来一轮 7 题（约 12 分钟）。
