## 4. 体积闸 K3 的处理（这次改判据是有理由的）

K3 原为 `os.path.getsize(PERSONA_MD) < 10000`，注释写着它的本意：
「改前 13,140 B，世界观移出后 < 10KB …… 但"世界观又被塞回来"（+4768 B）必然越界」。

- 它守的是 **世界观正文不许回到常驻前缀**（这件事由 K1 单独、逐句守着），
  不是"人设不许变长"；
- 本轮补的四节是**行为规则**，不是世界观正文；
- 12,468 + 4,768 = **17,236** ⇒ **世界观真要回流，13,500 这个新阈值照样拦得住**。

⇒ 阈值改 **13,500**，并把这段推算写进注释（下一个改的人不用重新猜）。
判据名从「体积已下降（< 10KB）」改为「体积有上界（世界观正文不许回流，< 13.5KB）」——
名字跟着语义走，不留下"名字说一件事、代码管另一件事"。

   需要跑一轮真机 7 题。
