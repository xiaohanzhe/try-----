  那会把 5 个章的 hometown 一次性全读进来）。分片总体积 228.6 KB。

加载策略（实测，_evidence/分片加载验证.txt）
- 「火把」语义落地：进一片区域只读 1 个分片 ≈ 0.79 ms。
- 走遍全部 61 片 = 48.5 ms；常驻内存增量 ≈ 0.74 MB。
- 索引加载 = 3.5 ms。
- 对比：1,013 个独立小文件全读 = 835 ms（OS 开销主导）⇒ 分片是正解。

代码（数据层与控制器，均为**追加式**改动）
- scene_system.load_scene(sid, dir, entry=None)：新增第二个来源（区域分片）。
  独立文件优先，缺失时才查分片；**独立文件存在但坏掉时不静默改读分片**
  （避免半坏数据悄悄换源）。老调用方 load_scene(sid) 行为完全不变。

  会全部加载失败（"函数写对了但产品用不上"的复发点）。
- **未改 load_index**：索引格式不动，减少回归面。
